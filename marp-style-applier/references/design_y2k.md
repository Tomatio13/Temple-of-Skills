# コンセプト: 「Nostalgic Future（ノスタルジック・フューチャー）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「90年代後半から2000年代の楽観的未来観、キラキラしたメタル、球体と3D」。過去が夢見た未来 — それは「Nostalgic Future」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: ノスタルジック、レトロフューチャー、楽観的、playful
- **Secondary Mood**: dreamy（夢見る）、glossy（光沢）、euphoric（陶酔的）
- **Visual Tension**: 「過去の未来」と「現在のノスタルジー」の時間的矛盾

### デザイン哲学
- **Chrome Dreams（クローム・ドリームス）**: 液体メタル、光沢のある表面、反射の美学
- **Bubble Aesthetics（バブル・エステティクス）**: 球体、泡、有機的なフォルム
- **Glitter & Sparkle（キラキラ）**: スパンコール、星、光の粒子
- **Optimistic Tech（楽観的なテック）**: テクノロジーは人間を救う、明るい未来

Text Colors（文字色）:
  - Pure Black        #000000  （主要テキスト）
  - Deep Blue         #1E40AF  （ダークブルー）

  - Electric Purple   #9333EA  （エレクトリックパープル）
  - White             #FFFFFF  （ダークモード用）

Accent Colors（差し色）:
  - Chrome Silver     #E8E8E8  （クロームシルバー）

**配色ルール:**
- パステルカラーとメタリックの組み合わせ
- グラデーション多用（虹色、夕焼け、オーロラ）

- 1スライドあたり最大4色（パステル2色＋メタリック1色＋アクセント1色）

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  英字:   "Verdana", "Comic Sans MS", "Impact", "Arial Black"
  特徴:   90s〜00sレトロ感、太字、インパクト重視
  ウェイト: Bold (700) / Black (900)
  サイズ:  H1: 64pt+ / H2: 48pt / H3: 32pt
  字間:   庅め（+2% 〜 +5%）

本文（BODY）:
  日本語: "M PLUS Rounded 1c", "Noto Sans JP", "游ゴシック"
  英字:   "Tahoma", "Arial", "Verdana"
  特徴:   丸みのあるフォント、可読性重視
  ウェイト: Regular (400)
  サイズ:  14pt 〜 18pt
  行間:   1.6 〜 1.8

装飾テキスト:
  アウトライン（白抜き）: 見出しで多用
  グロー効果: 外側発光
  グラデーションテキスト: 虹色に変化
```

**タイポグラフィ・ルール:**
- レトロなフォントを積極的に使用
- 見出しはアウトライン（白抜き）やグロー効果
- グラデーションテキストで虹色を表現
- 行間は標準的、詰めすぎない

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade: シンプルなフェード（0.6秒）
  - Dissolve: クロスディゾルブ（0.8秒）
  - Wipe: 横方向のワイプ（0.5秒）

エレメント・アニメーション（スライド内）:
  - Float-in: 漂うように現れる（0.8秒）
  - Scale-in: 拡大しながら現れる（0.6秒）
  - Spin: 回転しながら現れる（球体用、0.8秒）
  - Glow-pulse: 明滅する（強調ポイント、1秒周期）
  - Sparkle: キラキラ光る（装飾用、0.4秒）

タイミング:
  - トランジション: 0.6秒〜0.8秒（ゆったり）
  - エレメント: 0.6秒〜1秒
  - 遅延: ステップごとに0.2秒〜0.3秒のインターバル
```

**アニメーション・ルール:**
- 動きは「夢見るように」「漂うように」を心がける
- 硬い動き、カクカクした動きは禁止
- グロー、パルス、明滅を多用
- 「キラキラしている」ことが正解

### 共通レイアウト・ルール

**メタリック効果（Metallic Effects）:**
```
Chrome（クローム）:
  - グラデーション: グレー系（#E8E8E8 → #FFFFFF → #C0C0C0）
  - 光沢: 強い反射
  - 用途: ボタン、枠線、装飾

Liquid Gold（液体ゴールド）:
  - グラデーション: ゴールド系（#FFD700 → #FFA500 → #FFD700）
  - 光沢: 波打つような反射
  - 用途: アクセント、強調

Iridescent（虹色）:
  - グラデーション: 虹色（赤→オレンジ→黄→緑→青→紫）
  - 光沢: 多彩な反射
  - 用途: テキスト、装飾、背景
```

**球体とバブル（Spheres & Bubbles）:**
```
球体（Sphere）:
  - グラデーション: 放射状グラデーション
  - ハイライト: 左上に明るい部分（白〜淡い色）
  - シャドウ: 右下に暗い部分（同じ色の暗いトーン）
  - 用途: デコレーション、アイコン、ボタン
  - サイズ: 16px 〜 64px

バブル（Bubble）:
  - 半透明の球体
  - 透明度: 60% 〜 80%
  - 枠線: 極細の白（1px）
  - 用途: 背景装飾、テクスチャ
```

**キラキラ装飾（Sparkles）:**
```
星・スパンコール:
  - 形状: 四角星、丸星、十字星
  - サイズ: 8px 〜 24px
  - 色: ゴールド、シルバー、ホワイト
  - 配置: ランダム、タイトル周囲
  - アニメーション: 回転、明滅

光の粒子:
  - 小さな円形（4px 〜 8px）
  - 半透明（透明度50% 〜 80%）
  - 配置: 散らばるように
```

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Nostalgic Future（ノスタルジック・フューチャー）」**にあります。

**クローム・ドリームス:**
- 液体メタル、光沢のある表面
- 90s〜00sが夢見た未来の象徴
- テクノロジーは人間を幸せにするという楽観性

**バブル・エステティクス:**
- 球体、泡、有機的なフォルム
- 柔らかく、優しく、夢見る
- 暴力的な硬さの否定

**キラキラと輝き:**
- スパンコール、星、光の粒子
- 「キラキラしている」ことは良いこと
- 過去の未来は、いつだって輝いていた

**楽観的なテック:**
- テクノロジーへの信頼
- 明るい未来、希望に満ちた世界
- 21世紀は素晴らしいはずだった

**AIへの創造的許可:**
> 「過去の未来を夢見よう。」
>
> このガイドは、ノスタルジック・フューチャーへの招待状です。
> 具体的なルール（クローム、球体、キラキラ）を守りつつ、
> もっとメタリックに、
> もっとキラキラに、
> もっと夢見るように — それらを恐れないでください。

**最終判断基準:**
- もし画面が「2000年のWebサイト」を感じさせたら、それは正解です。
- もし余白が「キラキラしている」と感じたら、それは成功です。
- もし見る人が「懐かしい未来」を感じたら、それは最高の成果です。
