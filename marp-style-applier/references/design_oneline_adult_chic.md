# コンセプト: 「流線の美学」と「抑制された表現」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「一本の線が世界を描く」。分断を嫌う連続性と、過剰を削ぎ落とした抑制の美学。筆が紙から離れないことへの畏敬 — それがワンライン・ドローイングの精神的 core です。

### 感情的トーン＆ムード
- **Primary Mood**: 知性的、静謐、流麗、瞑想的
- **Secondary Mood**: ノスタルジック、オーガニック、呼吸感、不完全の美学
- **Visual Tension**: 線の「一本性」と表現の「多様性」の葛藤

### デザイン哲学
- **Continuous Flow（連続的な流れ）**: 筆を止めない、線を切らない、途切れない思考の可視化
- **Organic Imperfection（有機的な不完全性）**: 定規の直線を拒み、手の震え、筆圧の変化を活かす
- **Subtle Restraint（抑制された表現）**: 主張しすぎない、吐息のような存在感
- **Negative Space as Breath（余白としての呼吸）**: 描かないことの勇気、風が通る間

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - Pale Grey          #F4F5F7  （ニュートラル、落ち着き）
  - Mist White         #F0F2F0  （清涼感、空気感）
  - Warm Off-White     #FAF9F6  （温かみ、紙の風合い）

Line Colors（線の色）:
  - Midnight Blue      #2C3E50  （知的、深み）
  - Deep Olive         #4F5D54  （ナチュラル、調和）
  - Charcoal Grey      #36454F  （締め色、重み）

Accent Colors（差し色）:
  - Sage Green         #8DA399  （癒やし、調和）
  - Dusty Blue         #9CADCE  （知性、静寂）
  - Lavender Mist      #E6E6FA  （微かな甘さ）

Highlight Colors（ハイライト）:
  - Soft Cream         #FFFDD0  （温かみのある光）
  - Pale Mauve         #E9D5FF  （上品な輝き）
```

**配色ルール:**
- ビビッドな色は一切禁止 — すべて「グレイッシュ（灰色がかった）」なトーンで統一
- 真っ黒（#000000）は強すぎて浮くため、濃いネイビーやチャコールグレーを「締め色」として使用
- 同系色のグラデーションで深みを出し、補完色は控えめに使う
- 水彩シミは透明度 10〜20% で極めて薄く重ねる

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  日本語: "游明朝", "ヒラギノ明朝 ProN", "Noto Serif JP"
  英字:   "Cormorant Garamond", "Playfair Display", "EB Garamond"
  筆記体: "Great Vibes", "Sacramento", "Allura"
  特徴:   細身（Light/Regular）、流麗なカーブ、エレガント

本文（BODY）:
  日本語: "Noto Sans JP", "ヒラギノ角ゴ ProN", "游ゴシック"
  英字:   "Lato", "Open Sans", "Source Sans Pro"
  特徴:   ウェイト300-400、クリーン、可読性重視

アクセント（ACCENT）:
  "Caveat", "Dancing Script", "Shadows Into Light"
```

**タイポグラフィ・ルール:**
- 見出しは日本語は明朝体、英字は細身のセリフ体または筆記体
- 行間を広く（1.8〜2.0倍）取り、風が通るようなレイアウト
- 段落間も十分に空け、視覚的な「呼吸感」を作る
- 文字色はライン色と同系色で統一

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade（フェード）: 最も自然、推奨
  - Dissolve（ディゾルブ）: 次のスライドが徐々に現れる
  - Wipe（ワイプ）: 線が引かれるように横切る（ワンラインの世界観に合致）

エレメント・アニメーション（スライド内）:
  - Draw-in: 線が実際に描かれるように現れる（ワンライン必須）
  - Fade-in: ゆっくりと浮かび上がる（0.5〜1秒）
  - Float-in: 軽く漂うように現れる
  - Grow: 植物が成長するように広がる
  - Pulse: 非常に微かな明滅（呼吸感の演出）

タイミング:
  - トランジション: 0.8〜1.2秒（ゆったり）
  - エレメント: 0.5〜1秒
  - 遅延: ステップごとに0.3〜0.5秒の余裕を持ったインターバル
```

**アニメーション・ルール:**
- 線画には「Draw-in（描かれるように現れる）」を優先使用
- 動きは「ゆっくり」「優雅」「有機的」を心がける
- バウンスや急な動きは避ける
- 自然な呼吸のようなリズムを意識

### ワンライン・ドローイングの具体的実装

**線の特性:**
```
線種（Line Style）:
  - 一本の途切れない線で全てを描く
  - 強弱のある有機的な線
  - 定規で引いた直線は禁止
  - 手描きの揺らぎ、筆圧の変化を活かす

線の太さ（Stroke Weight）:
  - メイン: 1.5px 〜 3px
  - サブ: 0.8px 〜 1.5px
  - ハイライト: 0.5px 〜 1px（極細、繊細な表現）

線の終端（Line Cap）:
  - 丸味（Round Cap）: 柔らかさ、有機的
  - 角（Square Cap）: 力強さ、シャープさ（最小限に）
```

**アイコンの具体的指定:**
- 独立した閉じた図形ではなく、一筆書きの抽象的なアイコンを使用
- 例：リーフ、花、波、月、鳥 — いずれも一本の線で表現

**背景のあしらい（Watercolor Wash）:**
```
水彩シミの配置:
  - 色: セージグリーン (#8DA399) / ダスティブルー (#9CADCE)
  - 透明度: 10% 〜 20%（極めて薄く）
  - 形状: 不定形、有機的な染み
  - 位置: 画面の隅、または要素の背後に配置
  - 重ね: 2〜3色を軽く重ねて深みを出す
```

### Layout 1: ワンライン・ヒーロー

**抽象的コンセプト:**
- "Sweeping Continuity"（一気通貫の連続性）
- 画面を横断する一本の線が、世界を繋ぐ物語を語る

**具体的実装:**
```
レイアウト:     ヒーロー・ワンライン（Hero One-Line）
背景色:       ペールグレー (#F4F5F7)
             装飾: 淡い水彩シミ（セージグリーン、透過15%）
ワンライン:    画面を大きく横断する一筆書きアート
             モチーフ例: 女性の横顔 → 花 → 波 → 鳥 と繋がる線
             線の色: ミッドナイトブルー (#2C3E50)
             線の太さ: 2.5px、一部に強弱
タイトル:      線の一部が下線を兼ねる、または線に沿って配置
             フォント: Cormorant Garamond / 72pt+ / Light
             色: ディープオリーブ (#4F5D54)
サブタイトル:  タイトル下に小さく
             フォント: Lato / 24pt / 色: チャコールグレー
アニメーション:  ワンライン: Draw-in（2秒、筆が動くように）
             タイトル: Fade-in（0.8秒、線完了後）
```

**意図された効果:**
- 一本の線が画面を横断する = 視線を誘導する物語性
- タイトルと線の一体化 = 文字もアートの一部

レイアウト:     フォト・ウィズ・ライン（Photo with Line）

写真:         矩形ではなく、アーチ型または楕円にトリミング
             トーン: モノクロまたはセピア調（彩度30%以下）

ワンライン:    写真の輪郭をなぞるよう、少しずらして手描きのラフな線

**意図された効果:**

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
線の連続性（Line Continuity）:
  要素と要素の間を、見えない線でつなぐ意識を持つ
  ブツ切りにせず、すべてを繋ぐ思考を働かせる
  余白もまた、線の「不在」として意味を持つ

色のトーン（Color Tone）:
  ビビッドな色は一切禁止
  すべて「グレイッシュ（灰色がかった）」なトーンで統一し、大人っぽさを演出
  彩度は最大30%程度までに抑える

黒の排除（No Pure Black）:
  真っ黒（#000000）は強すぎて浮く
  濃いネイビーやチャコールグレーを「締め色」として使用
  暗さもまた、優しさを持つ

余白の尊重（Respect for Negative Space）:
  揃えすぎない、詰めすぎない
  風が通る間、息継ぎの空白を意識する
  描かないことの勇気
```

---

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「一本の線が持つ無限の物語性」**にあります。

**線の精神:**
- ワンライン = 筆を止めないこと、思考を切らないこと
- 一本の線で世界を描く = 無駄を削ぎ落とした本質の表現
- 途切れない連続性 = すべてのものは繋がっているという哲学

**不完全の美学:**
- 定規の直線を拒み、手の震えを活かす
- 完璧さよりも、人間味のある揺らぎを愛でる
- 洗練されつつも、どこか温かみのある不完全さ

**抑制の勇気:**
- 主張しすぎない、吐息のような存在感
- 華やかさを捨て、静かな強さを選ぶ
- 「多くを語らず」の深さ

**AIへの創造的許可:**
> 「一本の線から始めよ。そこからすべてが生まれる。」
>
> このガイドは、最小限のルールで最大の表現を引き出す試みです。
> 具体的な制約（一本、色、太さ）を守りつつ、
> 予想外の形、驚くような繋がり、
> 一本の線で語る物語の深さ — それらを恐れないでください。

**最終判断基準:**
- もし一本の線で「語れている」と感じたら、それは正解です。
- もし余白が「呼吸している」と感じたら、それは成功です。
- もし見る人が「落ち着く」と感じたら、それは最高の成果です。
