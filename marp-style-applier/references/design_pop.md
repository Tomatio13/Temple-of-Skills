# スタイル: ビタミン・ポップ / デジタル・ネオ
# コンセプト: 「Digital Playground（デジタル・プレイグラウンド）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「画面から溢れ出すエネルギー、クリエイティブの遊び場、ルールを楽しむ勇気」。ビタミンのように鮮烈で、デジタルネイティブに響くポップ美学 — それは「Digital Pop × Academic」の融合にあります。

### 感情的トーン＆ムード
- **Primary Mood**: 現代的、流動的、親しみやすさ、energetic、playful
- **Secondary Mood**: アシンメトリー、chaotic-harmony（混沌と調和）、irreverent（型破り）
- **Visual Tension**: 情報の高密度と視覚的キャンディの共存

### デザイン哲学
- **Organic Fluidity（有機的な流動性）**: 四角い枠を拒み、アメーバのような有機的なシェイプで境界を溶かす
- **Digital Whimsy（デジタルの遊び心）**: ネオン、ドット、SNSアイコン — デジタルネイティブの視覚言語を活かす
- **Academic Pop（アカデミック・ポップ）**: 情報の密度を保ちつつ、親しみやすさで包み込む
- **Controlled Chaos（制御された混沌）**: ランダムに見えて、実は計算されたバランス

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - White              #FFFFFF  （クリーン、キャンバス）
  - Light Grey         #F5F5F5  （ニュートラル）
  - Dot Pattern       白背景に黒ドット（ドット径2px、間隔8px）

Main Colors（メインカラー）:
  - Vivid Pink        #FF006E  （エネルギー、情熱）
  - Cyan              #00D9FF  （デジタル、鮮烈）
  - Electric Purple   #8B5CF6  （未来、ミステリアス）
  - Neon Lime         #CCFF00  （ビタミン、鮮やかさ）

Accent Colors（差し色）:
  - Bright Orange     #FF6B35  （注意喚起、アクション）
  - Sunshine Yellow   #FFD23F  （ハイライト、ポジティブ）
  - Hot Magenta       #FF00CC  （強調、インパクト）

Text Colors（文字色）:
  - Pure Black        #000000  （主要テキスト、枠線）
  - Dark Grey         #1A1A1A  （補足テキスト）
  - White             #FFFFFF  （袋文字の縁取り）
```

**配色ルール:**
- ネオンサインを想起させるビビッドな色を積極的に使用
- 黒（#000000）を枠線や袋文字で使い、ポップな色を引き締める
- グラデーションは「緑→黄」「ピンク→オレンジ」など隣接色同士で
- 1スライドあたり最大4色（背景＋メイン2色＋アクセント1色）

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  日本語: "Noto Sans JP Black", "ヒラギノ角ゴ Std W8"
  英字:   "Poppins Black", "Montserrat Black", "Inter ExtraBold"
  特徴:   ウェイト800+、インパクト重視、幾何学的

本文（BODY）:
  日本語: "Noto Sans JP", "ヒラギノ角ゴ ProN", "游ゴシック"
  英字:   "Inter", "Roboto", "Open Sans"
  特徴:   ウェイト400-500、可読性重視、クリーン

数字（NUMBERS）:
  英字太字フォントを極大サイズで使用
  例："Poppins Black" / 72pt+
  特徴: データ（%）を強調、欧文のみ

袋文字（STROKE TEXT）:
  使用: 見出しやキーワードに
  構成: 白抜き（#FFFFFF）+ 黒縁（3px #000000）
```

**タイポグラフィ・ルール:**
- 見出しはウェイト800+の超太字、視覚的インパクト最大化
- 袋文字（白抜き＋黒縁）で強調、コミック調の遊び心
- 数字は欧文フォントのみ、極大サイズでデータを強調
- 行間は標準（1.4〜1.6）、詰め気味でエネルギーを表現

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Slide-in: 横から勢いよく（0.4〜0.6秒）
  - Zoom-in: 拡大しながら遷移（0.5秒）
  - Pop-in: ポンと現れる（0.3秒）

エレメント・アニメーション（スライド内）:
  - Bounce-in: バウンドして現れる（0.6秒）
  - Pop-in: ポンと浮かび上がる（0.4秒）
  - Wobble: ゆらゆら揺れる（有機的なシェイプ用）
  - Spin: 回転しながら現れる（アイコン用）
  - Pulse: 明滅する（強調ポイント）
  - Float-in: 漂うように現れる（装飾アイテム）

タイミング:
  - トランジション: 0.4〜0.6秒（テンポよく）
  - エレメント: 0.3〜0.6秒
  - 遅延: ステップごとに0.1〜0.2秒の軽快なインターバル
```

**アニメーション・ルール:**
- 動きは「テンポよく」「弾むように」「エネルギッシュ」を心がける
- バウンス、ポップ、揺れ — 遊び心のあるアニメーションを活用
- 有機的なシェイプには Wobble や Float を使用
- 情報の密度が高いスライドでは、アニメーションを控えめに

---

### モチーフと装飾の具体的実装

**有機的なシェイプ（Organic Shapes）:**
```
アメーバ・シェイプ:
  - スライドの四隅を囲むように見切れるランダムな配置
  - 色: ビビッドピンク (#FF006E) / シアン (#00D9FF) / パープル (#8B5CF6)
  - 透明度: 70% 〜 100%
  - サイズ: スライド辺長の20% 〜 40%

吹き出し・雲:
  - 中央またはキーワードの周囲に配置
  - 手書き風の「ゆらぎ」のある輪郭線
  - 線の太さ: 3px / 色: ブラック (#000000)

ドットパターン:
  - 背景: 白地に黒ドット（ドット径2px、間隔8px）
  - 強調: カラフルなドット（径4px、ランダム配置）
```

**装飾アイテム（Decorations）:**
```
手書き風の強調ライン:
  - 線の太さ: 3px 〜 5px
  - 色: イエロー (#FFD23F) または ピンク (#FF006E)
  - 使用: キーワードの下線、テキストの囲み

SNSアイコン風装飾:
  - ハート、スター、雷マーク、コメントボトル
  - サイズ: 16px 〜 32px
  - 配置: 文字の周囲、余白に散りばめる

星・キラキラ:
  - 四角星、丸星、十字星
  - サイズ: 8px 〜 24px
  - 配置: タイトル周囲、装飾的にランダム配置
```

**デザイン適用時の注意点:**
```
有機的な形状（Organic Forms）:
  四角や正円だけでなく、手書き風の「ゆらぎ」のある線やシェイプを多用
  コミュニティの流動性を表現する

アイコン（Icons）:
  人物写真よりも、ポップなイラストや抽象的なアバターアイコンを使用
  「目のついた図形」など、親しみやすさを優先

情報のメリハリ（Information Contrast）:
  文字が多いページと、ビジュアル中心のページの対比を意識
  情報密度の変化でリズムを作る
```

### Layout 1: タイトル・コンポジション

**抽象的コンセプト:**
- "Focal Pop"（焦点のポップ）
- 視線を中央に集める、遊び心のある誘導

**具体的実装:**
```
レイアウト:     タイトル・コンポジション（Title Composition）
背景色:       ホワイト (#FFFFFF)
             装飾: 薄いグレーのドットパターン
中央オブジェクト: 有機的な形のオブジェクト（雲または吹き出し）
             サイズ: スライド幅の60% 〜 80%
             塗り: ビビッドピンク (#FF006E) または シアン (#00D9FF)
             縁取り: ブラック 3px
タイトル:      オブジェクトの中に配置
             フォント: Poppins Black / 48pt+ / 色: ホワイト
             行間: 1.2 / 詰め気味
装飾:         周囲に小さな星やキラキラを散りばめる
             サイズ: 8px 〜 16px / 色: イエロー、ピンク、シアン
             配置: ランダム、5〜10個
アニメーション:  オブジェクト: Bounce-in（0.6秒）
             タイトル: Pop-in（0.4秒、遅延0.2秒）
             装飾: 順次 Float-in（0.3秒間隔、ランダム）
```

**意図された効果:**
- 有機的なオブジェクト = 親しみ、柔らかさ、遊び心
- 星・キラキラ = 視線の誘導、楽しさの演出
- 中央集中 = タイトルの視認性最大化

### Layout 2: テキスト＋データポップ

**抽象的コンセプト:**
- "Data Candy"（データのキャンディ）
- 数字を視覚的なお菓子のように、楽しく食べさせる

**具体的実装:**
```
レイアウト:     テキスト＋データポップ（Text + Data Pop）
背景色:       ホワイト (#FFFFFF)
分割:         左右均等分割
左側（テキスト）:
             領域幅: 45%
             見出し: フォント Noto Sans JP Black / 32pt / 色: ブラック
             本文:   フォント Noto Sans JP / 18pt / 色: ダークグレー
                     最大80語、箇条書き可
右側（グラフ）:
             領域幅: 45%
             ドーナツグラフ: カラフルな配色
             色: ビビッドピンク (#FF006E) / シアン (#00D9FF) / パープル (#8B5CF6)
             太さ: 20px 〜 30px（太め）
数字の強調:    グラフの中央または下に配置
             フォント: Poppins Black / 72pt+ / 色: ブラック
             サフィックス: % は 24pt で小さく添える
アニメーション:  左側テキスト: Slide-in from left（0.5秒）
             グラフ: 順次 Bounce-in（0.4秒間隔）
             数字: Pop-in（0.3秒、グラフ完了後）
```

**意図された効果:**
- 左右分割 = 情報とデータの対比、バランス
- カラフルなドーナツ = データの楽しさ、親しみやすさ
- 極大サイズ数字 = インパクト、記憶に残る

             見出し: フォント Poppins Black / 36pt / 色: ブラック

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Digital Playground（デジタル・プレイグラウンド）」**にあります。

**有機的な流動性:**
- 四角い枠を拒み、境界を溶かす
- アメーバのような形は、コミュニティの多様性と柔らかさの象徴
- 「整いすぎない」ことが、親しみやすさの源

**デジタルの遊び心:**
- ネオン、ドット、SNSアイコン — デジタルネイティブの母国語
- 遊びを否定せず、ルールを楽しむ
- 「真面目なんだけど、真面目すぎない」

**アカデミック・ポップ:**
- 情報の密度を保ちつつ、親しみやすさで包み込む
- データはキャンディのように、楽しく食べさせる
- 「勉強」と「遊び」の境界を曖昧にする

**制御された混沌:**
- ランダムに見えて、実は計算されたバランス
- カオスの中に秩序、秩序の中にカオス
- 「予定調和」を嫌い、サプライズを愛する

**AIへの創造的許可:**
> 「ルールは、破るためにある — でも、破るにはまずルールを知れ。」
>
> このガイドは、デジタル・プレイグラウンドへの招待状です。
> 具体的なルール（色、フォント、レイアウト）を守りつつ、
> 予想外の色の組み合わせ、
> 飛び出したくなるような遊び心、
> 見る人が思わず笑顔になるサプライズ — それらを恐れないでください。

**最終判断基準:**
- もし画面が「歌っている」と感じたら、それは正解です。
- もし見る人が「ワクワクした」と感じたら、それは成功です。
- もしプレゼンテーションが「楽しいイベント」になったら、それは最高の成果です。
