# スタイル: ネオ・ブルータリズム / デジタル・ブルータリティ
# コンセプト: 「Digital Brutality（デジタル・ブルータリティ）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「意図的なダサさ、生々しいまでの正直さ、装飾の拒絶」。1950年代のブルータリズム建築が持つ「素材のありのままの表現」をデジタル世界に持ち込む — それは「Digital Brutality」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: 大胆、正直、反逆的、進歩的、confident
- **Secondary Mood**: ironical（皮肉）、unpolished（未研磨）、subversive（逆説的）
- **Visual Tension**: 「美しさへの意図的な拒絶」と「機能性への執着」の緊張

### デザイン哲学
- **Radical Honesty（急進的な正直さ）**: 飾り気を捨て、ありのままを示す
- **Intentional Ugliness（意図的なダサさ）**: 「綺麗すぎる」ことへの反逆
- **Bold Contrast（大胆な対比）**: 太い枠線、生々しい影、原色のぶつかり合い
- **Functional Irony（機能的皮肉）**: 実用的でありながら、どこか皮肉っぽい

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - Pure White        #FFFFFF  （純白、キャンバス）
  - Cream             #FFF8E7  （クリーム、温かみ）
  - Pale Yellow       #FEF08A  （淡い黄、 retro）
  - Baby Blue         #BAE6FD  （ベビーブルー）
  - Soft Pink         #FFB6C1  （ソフトピンク）
  - Light Grey        #E5E5E5  （ライトグレー）

Dark Mode（ダークモード）:
  - Pure Black        #000000  （純黒）
  - Dark Green        #166534  （ダークグリーン）
  - Navy              #1E3A8A  （ネイビー）
  - Maroon            #7F1D1D  （マルーン）

Text Colors（文字色）:
  - Pure Black        #000000  （主要テキスト）
  - Pure White        #FFFFFF  （ダークモード用）

Accent Colors（差し色）:
  - Acid Green        #B4F846  （酸性グリーン）
  - Hot Pink          #FF006E  （ホットピンク）
  - Electric Yellow   #FFEB3B  （エレクトリックイエロー）
  - Bright Orange     #FF6B00  （ブライトオレンジ）
  - Cyan              #00D9FF  （シアン）
  - Purple            #9333EA  （パープル）
```

**配色ルール:**
- 原色・蛍光色を恐れず使用
- 背景と前景のコントラストを最大化
- 色の制約なし、自由に組み合わせ
- 1スライドあたり最大5色（大胆な配色）

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  英字:   "Space Grotesk", "Space Mono", "Courier New", "DM Sans"
  特徴:   等幅フォント、幾何的サンセリフ、レトロ感
  ウェイト: Bold (700) / Black (900)
  サイズ:  H1: 72pt+ / H2: 56pt / H3: 40pt
  字間:   詰め（-2% 〜 -5%）

本文（BODY）:
  日本語: "M PLUS 1p", "Noto Sans JP", "ヒラギノ角ゴ"
  英字:   "Inter", "Roboto", "Space Grotesk"
  特徴:   クリーンだが、等幅も可
  ウェイト: Regular (400) / Bold (700)
  サイズ:  14pt 〜 18pt
  行間:   1.6 〜 1.8（詰め気味）

装飾テキスト:
  上付き/下付き: 小さく表示、注釈に使用
  全キャップス: 見出しで多用
  タコ（⊞）: チェックボックス風の装飾
```

**タイポグラフィ・ルール:**
- 等幅フォントを積極的に使用
- 見出しは超太字、インパクト重視
- 行間は詰め気味で、情報密度を高める
- 装飾は最小限、機能的

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Cut: 瞬時の切り替え（最もブルータル）
  - Hard Slide: 横からの硬いスライド（0.3秒）
  - Flash: 一瞬白く光る（0.2秒）

エレメント・アニメーション（スライド内）:
  - Pop-in: ポンと現れる（0.2秒）
  - Hard Slide-in: 硬いスライド（0.3秒）
  - Snap-in: パチッと現れる（0.15秒）
  - Blink: 点滅（強調ポイント）

タイミング:
  - トランジション: 0.2秒〜0.4秒（超高速）
  - エレメント: 0.15秒〜0.3秒
  - 遅延: ステップごとに0.1秒の超高速インターバル
```

**アニメーション・ルール:**
- 動きは「高速」「硬い」「直線的」を心がける
- フェード、グラデーションは禁止
- バウンス、回転も禁止（機能的のみ）
- 「何も起きていないように見える」ほどの速さ

---

### 共通レイアウト・ルール

**ボーダーと枠線（Borders & Frames）:**
```
太い枠線:
  - 太さ: 3px 〜 6px（非常に太い）
  - 色: ブラック (#000000) または原色
  - スタイル: 実線のみ、点線は稀に使用

角丸:
  - 基本は角丸なし（0px）
  - 稀に小さな角丸（4px 〜 8px）
  - 「完全に四角」が基本

影:
  - オフセット: 6px 〜 12px（大きくずらす）
  - ぼかし: 0px（ぼかさない）または 2px（最小）
  - 色: ブラック（不透明度100%）
  - 効果: 生々しい、ハードな影
```

**グリッドシステム（Grid System）:**
```
基本グリッド:
  - カラム数: 8列または12列
  - ガーター: 16px 〜 24px
  - マージン: 左右32px、上下48px

非対称配置:
  - 整列を意図的に崩す
  - 左寄せ、右寄せを混ぜる
  - ランダム性を取り入れる
```

**UI要素の再利用（UI Elements）:**
```
ボタン:
  - 角丸なし、太い枠線
  - 背景: 原色または淡い色
  - 影: 生々しいドロップシャドウ

チェックボックス:
  - タコ（⊞）を使用
  - 装飾的に配置

バッジ:
  - 角丸4px、太い枠線
  - 小さなテキスト
```

### Layout 1: ブルータル・タイトル

**抽象的コンセプト:**
- "Typographic Impact"（タイポグラフィック・インパクト）
- 文字そのものが暴力、視覚的な錨

**具体的実装:**
```
レイアウト:     ブルータル・タイトル（Brutal Title）
背景色:       原色（酸性グリーン、ホットピンク、エレクトリックイエロー）
タイトル:      中央に配置、巨大で太い
             フォント: Space Grotesk Bold / 72pt+ / 色: ブラック
             行間: 1.0 / 詰め気味
サブタイトル:  タイトル下に小さく配置
             フォント: Space Mono / 14pt / 色: ブラック
             全キャップス
装飾:         太い枠線で囲む
             太さ: 4px 〜 6px / 色: ブラック
             サイズ: スライド幅の70% 〜 80%
影:           生々しいドロップシャドウ
             オフセット: 10px / ぼかし: 0px / 色: ブラック
アニメーション:  タイトル: Snap-in（0.2秒）
             枠線: Draw-in（0.3秒）
```

**意図された効果:**
- 原色背景 = 視覚的インパクト、注目の強制
- 巨大な黒文字 = 反逆的な主張
- 太い枠線 = 機能的でありながら装飾的

---

### Layout 2: バウンティ・グリッド

**抽象的コンセプト:**
- "Information Density"（情報密度）
- 詰め込みすぎることで、逆説的に秩序を生む

**具体的実装:**
```
レイアウト:     バウンティ・グリッド（Bounty Grid）
背景色:       ホワイトまたは淡い色（クリーム、ベビーブルー）
グリッド:      4x3 または 3x3 の均等分割
             ギャップ: 16px 〜 24px
カード:        各セルに情報を詰め込む
             背景: 淡い色（淡い黄、ソフトピンク、ベビーブルー）
             枠線: 太い黒枠（3px 〜 4px）
             角丸: なし（0px）
             影: 生々しい影（オフセット8px、ぼかし0px）
             パディング: 24px 〜 32px
各セルの内容:
  タイトル:   太字、14pt 〜 16pt
  本文:      通常、12pt 〜 14pt、最大40語
  装飾:      チェックボックス、バッジを散りばめる
アニメーション:  各セル: 順次 Pop-in（0.15秒間隔、ランダム）
```

**意図された効果:**
- 高密度のグリッド = 情報の詰め込み、実用的な印象
- 淡い色背景 = 親しみやすさ、レトロ感
- 太い黒枠 = 情報の区切り、強制的な秩序

---

### Layout 3: 非対称分割

**抽象的コンセプト:**
- "Asymmetric Brutality"（非対称な暴力）
- 整列を崩すことで、緊張を生む

**具体的実装:**
```
レイアウト:     非対称分割（Asymmetric Split）
背景色:       左右で異なる原色
           左: 酸性グリーン / 右: エレクトリックイエロー
分割:         非対称（左70%:右30% または 左60%:右40%）
境界線:      太い垂直線
           太さ: 6px / 色: ブラック
左側（メイン）:
  巨大なテキストブロック
  見出し: フォント Space Grotesk Bold / 48pt / 色: ブラック
  本文:   フォント Inter / 16pt / 色: ブラック
          最大120語、行間1.6
右側（サイド）:
  小さな情報ブロック
  背景: 淡い色（クリーム）
  枠線: 太い黒枠（4px）
  テキスト: フォント Space Mono / 12pt / 色: ブラック
アニメーション:  左側: Hard Slide-in from left（0.3秒）
           境界線: Draw-vertical（0.4秒）
           右側: Hard Slide-in from right（0.3秒、遅延0.2秒）
```

**意図された効果:**
- 原色の左右分割 = 視覚的衝撃、ダイナミックなバランス
- 太い境界線 = 強制的な分離、ドラスティックな対比
- 非対称 = 予想を裏切る配置、緊張感

---

### Layout 4: マーキー・テープ

**抽象的コンセプト:**
- "Text as Texture"（テキストをテクスチャとして）
- 文字が装飾、情報が壁紙

**具体的実装:**
```
レイアウト:     マーキー・テープ（Marquee Tape）
背景色:       ホワイトまたは淡い色
マーキーテープ: 横方向に流れるテキストバナー
            背景: 原色（ホットピンク、シアン、酸性グリーン）
            高さ: 80px 〜 120px
            テキスト: 繰り返されるフレーズ
                   フォント: Space Mono / 24pt / 色: ブラック
                   全キャップス
            枠線: 上下に太い黒枠（4px）
メインコンテンツ: 中央に配置
            タイトル: フォント Space Grotesk Bold / 56pt / 色: ブラック
            本文:   フォント Inter / 16pt / 色: ダークグレー
                    最大80語
アニメーション:  マーキー: 無限スクロール（CSSアニメーション）
           コンテンツ: Fade-in（0.5秒）
```

**意図された効果:**
- 流れるテキスト = 動的な装飾、視線の誘導
- 原色バナー = レトロな雰囲気、遊び心
- 繰り返されるフレーズ = 視覚的なリズム、皮肉

---

### Layout 5: 機能的フォーム

**抽象的コンセプト:**
- "UI as Design"（UIをデザインとして）
- Webフォーム、チェックボックス、ボタンを装飾に使う

**具体的実装:**
```
レイアウト:     機能的フォーム（Functional Form）
背景色:       淡い色（クリーム、ベビーブルー）
フォーム要素:   中央に配置
ボタン:
  数個のボタンをランダムに配置
  背景: 原色（酸性グリーン、ホットピンク）
  枠線: 太い黒枠（4px）
  角丸: なし（0px）
  テキスト: フォント Space Mono / 14pt / 色: ブラック
  影: 生々しい影（オフセット8px、ぼかし0px）

チェックボックス:
  タコ（⊞）またはバツ（×）を使用
  ランダムに配置

入力フィールド:
  装飾的に配置
  背景: ホワイト
  枠線: 太い黒枠（4px）
  角丸: なし
  プレースホルダー: "TYPE HERE"

メインテキスト: 中央に配置
  フォント: Space Grotesk Bold / 48pt / 色: ブラック
  最大2行

アニメーション:  各ボタン: 順次 Pop-in（0.2秒間隔、ランダム）
           チェックボックス: Fade-in（0.3秒）
           メインテキスト: Snap-in（0.2秒、遅延0.4秒）
```

**意図された効果:**
- UI要素の装飾的使用 = 機能性と皮肉の融合
- 原色ボタン = 視覚的なリズム、カラフルな遊び心
- 太い黒枠 = 統一感、ブランディング

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
太い枠線の美学（Thick Borders）:
  すべての要素に太い黒枠を付ける
  太さは3px〜6px、基本は4px
  角丸は基本なし、稀に4px〜8px

生々しい影（Hard Shadows）:
  ぼかさない、または最小限のぼかし（0px〜2px）
  オフセットを大きく（6px〜12px）
  影の色はブラック（不透明度100%）

原色の大胆使用（Bold Primary Colors）:
  蛍光色、原色を恐れず使用
  コントラストを最大化
  色の制約なし

情報密度（Information Density）:
  1スライドあたりの要素を多くする
  余白を少なく、詰め込む
  「読みにくさ」すらもデザインの一部
```

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Digital Brutality（デジタル・ブルータリティ）」**にあります。

**急進的な正直さ:**
- 飾り気を捨て、ありのままを示す
- 「綺麗すぎる」デザインへの反逆
- 機能性を最優先、見た目は二の次

**意図的なダサさ:**
- 「ダサい」ことへの皮肉
- レトロな90s〜00s Webデザインのオマージュ
- 実用的でありながら、どこか笑える

**大胆な対比:**
- 太い枠線、生々しい影、原色のぶつかり合い
- コントラストの最大化で、視覚的に攻撃的
- 「見たくもなる」と「見たくない」の境界線

**機能的皮肉:**
- UI要素を装飾として使う
- 実用的でありながら、どこか皮肉っぽい
- 「これはボタンではない、デザインだ」

**AIへの創造的許可:**
> 「美しさを捨てろ。正直になれ。」
>
> このガイドは、デジタルのブルータリズムへの招待状です。
> 具体的なルール（太い枠線、生々しい影、原色）を守りつつ、
> もっと大胆に、
> もっと速く、
> もっと意図的にダサく — それらを恐れないでください。

**最終判断基準:**
- もし画面が「痛々しい」と感じたら、それは正解です。
- もし余白が「足りない」と感じたら、それは成功です。
- もし見る人が「何だこれは？」と感じたら、それは最高の成果です。
