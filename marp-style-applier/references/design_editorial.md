# スタイル: モダン・エディトリアル / ライフスタイル雑誌風 / 温かみと洗練
# コンセプト: 「物語ある余白（Storytelling Whitespace）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「ページを開いたときの静寂、紙から伝わる温かみ、言葉が呼吸する空間」。Kinfolkのようなライフスタイル雑誌が持つ美学 — それは過剰を削ぎ落とした「物語ある余白」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: 穏やか、情緒的、オーガニック、知的、 slow living
- **Secondary Mood**: ノスタルジック、tactile（触覚的）、intimate（親密な）、honest（素朴な）
- **Visual Tension**: 「何もない」豊かさと「語りかける」静けさの共存

### デザイン哲学
- **Slow Design（スロー・デザイン）**: 急ぐことなく、ゆっくりと目を巡らせる余白の美意識
- **Tactile Typography（触覚的なタイポグラフィ）**: 紙の質感、インクの滲み、文字の体温
- **Organic Minimalism（有機的なミニマリズム）**: 機械的な完璧さよりも、人間味のある不整斉
- **Narrative Whitespace（物語ある余白）**: 何もない空間に、想像力を委ねる勇気

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - Sand Beige         #F3F0EB  （温かみ、土、自然）
  - Warm Grey          #EBEBEB  （穏やか、調和）
  - Cream White        #FAF8F5  （乳白、紙の風合い）
  - Soft Taupe         #E8E0D5  （上品なくすみ）

Text Colors（文字色）:
  - Charcoal Grey      #333333  （主要テキスト、漆黒は禁止）
  - Warm Brown         #5C4033  （強調、温かみのある濃さ）
  - Soft Grey          #666666  （補足テキスト、キャプション）
  - Muted Tan          #8B7E74  （本文、目に優しい）

Accent Colors（差し色）:
  - Terracotta         #E07A5F  （情熱、大地、陶器）
  - Olive Green        #708D81  （自然、調和、穏やかさ）
  - Dried Rose         #B5838D  （上品な華やかさ）
  - Warm Mustard       #D4A373  （秋、温かみのあるアクセント）
```

**配色ルール:**
- 寒色系（青白い色、鮮やかなブルー）は一切回避
- 全体的に温かみのあるトーン（色温度5000K以下のイメージ）で統一
- 色数は1スライドあたり最大3色（背景＋文字＋アクセント1色）
- 写真と同系色のテキストで統一感を演出

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  日本語: "游明朝", "ヒラギノ明朝 ProN", "Noto Serif JP"
  英字:   "Playfair Display", "Cormorant Garamond", "EB Garamond"
  特徴:   エレガント、Classic Serif、ウェイト400-600
  強調:   重要な単語は *Italic*（斜体）で強調

本文（BODY）:
  日本語: "Noto Sans JP", "ヒラギノ角ゴ ProN", "游ゴシック"
  英字:   "Lato", "Open Sans", "Source Sans Pro"
  特徴:   幾何学的、クリーン、可読性重視、ウェイト300-400

数字（NUMBERS）:
  オールドスタイル数字、またはセリフ体の数字
  例："Playfair Display" の figures=oldstyle
  特徴: 小文字の高さに揃った、優雅な数字
```

**タイポグラフィ・ルール:**
- 巨大な見出し（H1: 64pt+）と小さな本文（16-18pt）で極端なサイズ差をつける
- 行間は広く（1.6〜2.0）取り、風が通るように
- 文字間隔（tracking）は見出しで少し詰め（-0.5〜-1%）、本文で標準
- 段落間は十分に空け（行間の1.5〜2倍）、視覚的な「息継ぎ」を作る

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade（フェード）: 推奨、最も自然
  - Dissolve（ディゾルブ）: ページをめくるような感覚
  - Slow Slide: 非常にゆっくりとした横スライド（2秒以上）

エレメント・アニメーション（スライド内）:
  - Fade-in: ゆっくりと浮かび上がる（0.8〜1.2秒）
  - Slide-up: 下から静かに現れる（0.6〜1秒）
  - Type-in: タイプライターのように一文字ずつ（引用文など）
  - Scale-in: ゆっくりと拡大しながら現れる（キービジュアル）
  - Draw-line: 細い線が引かれるように（装飾線）

タイミング:
  - トランジション: 1〜1.5秒（ゆったり）
  - エレメント: 0.6〜1秒
  - 遅延: ステップごとに0.4〜0.6秒の余裕を持ったインターバル
```

**アニメーション・ルール:**
- 動きは「ゆっくり」「静かに」「優雅」を心がける
- バウンス、急な動き、派手なエフェクトは一切禁止
- 自然な呼吸のようなリズムを意識
- 「紙の上で物語が紡がれる」感覚を維持

---

### 画像スタイルの具体的実装

**写真の特性:**
```
画像スタイル（Image Style）:
  - 自然光で撮影された写真（硬いストロボは禁止）
  - フィルム粒子の質感（Film Grain）を活かす
  - 色温度: 温かみのあるトーン（5000K以下）
  - コントラスト: ソフト（ハイコントラスト禁止）

トリミング形状（Crop Shapes）:
  - アーチ窓型: 上部が半円、下部は矩形
  - 角丸長方形: 角の半径 8px 〜 24px
  - 円形: 完全な円、または楕円
  - 裁ち落とし: フチなし、画像端まで配置

配置の原則:
  - 一つのスライドに最大2枚の写真
  - 写真は「言葉を補完する」役割、主役になりすぎない
  - 余白を十分に取り、写真を「孤立」させない
```

**共通レイアウト・ルール:**
```
囲み枠禁止（No Borders）:
  重たい枠線やボックスは一切使わない
  余白（スペース）で要素を区切る
  区切りが必要な場合は極細の線（0.5px）を使用

文字の階層（Type Hierarchy）:
  巨大な見出し（64pt+）と小さな本文（16-18pt）
  極端なサイズ差で視覚的リズムを作る
  見出しと本文のフォントも対比させる（明朝 vs ゴシック）

余白の美学（Whitespace as Design）:
  余白は「空いている」のではなく「意図的に配置された」
  マージンは最小48px、理想的には64px以上
  要素同士の間隔に「物語を感じさせる」
```

### Slide 1: 表紙 / カバー

**抽象的コンセプト:**
- "Silent Invitation"（静かな招待状）
- 雑誌の表紙を開いたときの期待感、物語への入り口

**具体的実装:**
```
レイアウト:     雑誌のカバー風（Magazine Cover）
背景色:       サンドベージュ (#F3F0EB)
写真:         右半分に裁ち落とし（フチなし）で配置
             サイズ: スライド幅の50%、上下も端まで
             トーン: 自然光、フィルム粒子、温かみのある色味
タイトル:      左半分に巨大な明朝体で複数行に配置
             フォント: Playfair Display / 72pt+ / SemiBold
             色: チャコールグレー (#333333)
             配置: 左寄せ、上から35%の位置
サブタイトル:  タイトル下に小さく
             フォント: Lato / 18pt / 色: ソフトグレー (#666666)
装飾:         タイトルとサブタイトルの間に極細水平線
             線の太さ: 0.5px / 長さ: タイトル幅の30% / 色: テラコッタ (#E07A5F)
アニメーション:  写真: Fade-in（1秒）
             タイトル: Fade-in（0.8秒、遅延0.3秒）
             装飾線: Draw-line（0.6秒、左から右へ）
             サブタイトル: Fade-in（0.5秒、遅延0.4秒）
```

**意図された効果:**
- 雑誌の表紙 = 物語への入り口、期待感の演出
- 裁ち落とし写真 = 現代的、洗練された印象
- 極細の線 = 上品な区切り、余白の活用

---

### Slide 2: フィロソフィー / 引用

**抽象的コンセプト:**
- "Meditative Pause"（瞑想的な一時停止）
- 読む人を思考へ誘う、静寂の空間

**具体的実装:**
```
レイアウト:     中央配置の引用（Centered Quote）
背景色:       サンドベージュ (#F3F0EB) 単色
引用テキスト:   短く力強いメッセージを中央に配置
             フォント: Playfair Display Italic / 48pt+ / Light
             色: チャコールグレー (#333333)
             最大20語、2〜3行
             行間: 1.8
装飾:         背景に巨大な引用符（""）
             フォント: Playfair Display / 200pt+ / 色: テラコッタ (#E07A5F)
             透明度: 5% 〜 10%（極めて薄く）
             配置: テキストの背後に重ねる
著者名:        引用文の下、右寄せで小さく
             フォント: Lato / 16pt / 色: ソフトグレー
             前にem dash（—）を配置
アニメーション:  引用符: Fade-in（1秒）
             テキスト: Type-in（1.5秒、一文字ずつ）
             著者名: Fade-in（0.5秒、テキスト完了後）
```

**意図された効果:**
- 中央配置 = 瞑想、内省への誘い
- イタリック体 = 親しみ、柔らかさ、語りかけるトーン
- 薄い引用符 = 装飾でありながら、邪魔にならない

---

### Slide 3: サービスの流れ / プロセス

**抽象的コンセプト:**
- "Vertical Narrative"（垂直の物語）
- 時間の流れを上から下へ、丁寧に紡ぐ

**具体的実装:**
```
レイアウト:     ステップ・ナラティブ（Step Narrative）
背景色:       ウォームグレー (#EBEBEB)
フロー:        上から下への垂直レイアウト
             ステップ間隔: 64px 〜 80px（余白多め）
ステップ番号:  小さな円の中に数字
             円のサイズ: 32px × 32px
             塗り: テラコッタ (#E07A5F) または オリーブグリーン (#708D81)
             数字色: ホワイト (#FFFFFF)
             フォント: Lato Bold / 16pt
接続線:       非常に細い点線でステップをつなぐ
             線の太さ: 1px / スタイル: dotted
             色: ソフトグレー (#666666)
ステップタイトル: フォント: Playfair Display / 28pt / 色: チャコールグレー
ステップ説明:   フォント: Lato / 18pt / 色: ソフトグレー / 最大30語
画像:         各ステップの横に小さく円形に切り抜いた写真
             サイズ: 80px × 80px / 配置: ステップ番号の右隣
アニメーション:  各ステップ: 順次 Slide-up + Fade-in（0.6秒間隔）
             接続線: Draw-line（1.5秒、上から下へ）
```

**意図された効果:**
- 垂直レイアウト = 時間の流れ、物語の進行
- 点線 = 繋がりを示しつつ、重くない
- 円形写真 = 親しみ、ナチュラルな印象

---

### Slide 4: データ・グラフ

**抽象的コンセプト:**
- "Data as Story"（データとしての物語）
- 数字を冷たい事実ではなく、温かい物語として語る

**具体的実装:**
```
レイアウト:     クリーンな折れ線グラフ（Clean Line Chart）
背景色:       クリームホワイト (#FAF8F5)
グラフ:        グリッド線（目盛り）を排除した極細の折れ線
             線の太さ: 2px 〜 3px
             線の色: テラコッタ (#E07A5F) / オリーブグリーン (#708D81) の2色
             データ点: 小さな円（半径4px）でマーク
配色:         アースカラーで統一
             - オリーブ (#708D81)
             - ブラウン (#8B7E74)
             - ベージュ (#D4A373)
キャプション:   グラフの横に「説明的な文章（段落）」を配置
             フォント: Lato / 16pt / 行間1.8 / 色: ソフトグレー
             最大80語、物語を補足する文章
凡例:         グラフの上部に小さく配置
             フォント: Lato / 14pt / 色: チャコールグレー
アニメーション:  折れ線: Draw-line（2秒、左から右へ）
             データ点: Fade-in（0.3秒、線到達後）
             キャプション: Fade-in（0.8秒）
```

**意図された効果:**
- グリッド線排除 = ノイズのない、クリーンな印象
- アースカラー = 温かみ、親しみやすいデータ
- 段落キャプション = 数字に物語を与える

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「物語ある余白（Storytelling Whitespace）」**にあります。

**スロー・デザインの精神:**
- 急ぐことなく、ゆっくりと目を巡らせる余白の美意識
- 情報過多の時代における「減らす勇気」
- 一瞬一瞬を丁寧に味わう slow living の哲学

**触覚的なタイポグラフィ:**
- 紙の質感、インクの滲み、文字の体温
- デジタルでありながら、アナログの温かみを感じさせる
- 読むこと、触れること、感じることの統一

**有機的なミニマリズム:**
- 機械的な完璧さよりも、人間味のある不整斉
- 自然光のような柔らかさ、フィルム粒子のような温かみ
- 「整いすぎない」ことの美しさ

**物語ある余白:**
- 何もない空間に、想像力を委ねる勇気
- 余白は「無」ではなく、読む人の心で満たされる「可能性」
- 語りすぎないことの力

**AIへの創造的許可:**
> 「ページを開いたときの静寂を思い出せ。」
>
> このガイドは、過剰を削ぎ落とした「物語ある余白」への招待状です。
> 具体的なルール（フォント、色、余白）を守りつつ、
> 読む人の心に静かに響く言葉、
> 見る人の想像力をかき立てる空間、
> ゆっくりと紡がれる物語 — それらを恐れないでください。

**最終判断基準:**
- もしページが「呼吸している」と感じたら、それは正解です。
- もし余白が「物語を語っている」と感じたら、それは成功です。
- もし見る人が「落ち着きを取り戻す」と感じたら、それは最高の成果です。
