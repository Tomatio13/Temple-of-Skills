# コンセプト: 「古典（クラシック）と現代ポップの融合」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「永遠の美」を象徴する古典的な大理石彫刻と、「一瞬の楽しさ」を表現する現代ポップカルチャーの衝突的な融合。時間軸を超えた対話を生み出すシュルレアリスム的遊び心。

### 感情的トーン＆ムード
- **Primary Mood**: 遊戯的、反骨、ノスタルジック・フューチャー
- **Secondary Mood**: アイロニカル、カオティック・ハーモニー、視覚的サスペンス
- **Visual Tension**: 静止した古典美 × 動的なポップエネルギーの並置

### デザイン哲学
- **Anachronistic Juxtaposition（時代錯誤の並置）**: 異なる時間軸の要素を意図的に衝突させる
- **High-Contrast Irony（高コントラストのアイロニー）**: 厳格な古典形式と軽薄なポップ要素の対比
- **Surrealist Narrative（シュルレアリスム的物語性）**: 非論理的な組み合わせに含意される物語
- **Vaporwave Aesthetic（ヴェイパーウェイヴ美学）**: 90年代テクノロジー・ノスタルジアとネオン色彩の融合

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Primary Backgrounds（背景色）:
  - Electric Purple    #9B59B6  （ミステリアス、サイバー）
  - Sunshine Yellow    #F1C40F  （エネルギー、注意喚起）
  - Hot Pink           #FF69B4  （ポップ、遊び心）
  - Neon Green         #39FF14  （未来、テクノロジー）
  - Vivid Orange       #FF5F1F  （情熱、アクション）
  - Sky Blue           #87CEEB  （軽快、爽やか）

Accent Colors（差し色）:
  - Cyan               #00FFFF  （ヴェイパーウェイヴ定番）
  - Magenta            #FF00FF  （レトロポップ）
  - White              #FFFFFF  （テキスト、ハイライト）
  - Black              #000000  （テキスト、コントラスト）
```

**配色ルール:**
- 各スライドは単色背景（One Solid Color）を使用
- アクセサリーの色とテキストアクセント色をマッチングさせる
- 補完色（Complementary Colors）で対比効果を強調

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  Primary:   "Helvetica Bold", "Futura Bold", "Arial Black"
  Secondary: "Cooper Black", "Impact", "Bebas Neue"
  特徴:      ウェイト700+、幾何学的、視覚的インパクト重視

本文（BODY）:
  Primary:   "Helvetica", "Roboto", "Inter"
  Secondary: "Open Sans", "Source Sans Pro"
  特徴:      ウェイト400-500、クリーン、可読性確保

アクセント（ACCENT）:
  "Bangers", "Comic Neue", "Press Start 2P"（レトロゲーム調）
```

**タイポグラフィ・ルール:**
- 見出しは **ALL CAPS** で統一（視認性向上）
- テキスト最小化：各スライド最大20語
- フォントサイズ階層：H1(72pt+) / H2(48pt+) / Body(24pt+)
- ビビッド背景には白または黒の高コントラストテキスト

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Slide-in（横スライド）
  - Zoom-out（ズームアウト）
  - Fade（フェード） ※最小限に使用

エレメント・アニメーション（スライド内）:
  - Pulse:     キーワードや数字の強調
  - Bounce:    アクセント要素（風船ガム等）
  - Float:     装飾アイコンの浮遊感
  - Typewriter: テキストの逐次表示
  - Scale:     ヒーロー画像の演出

タイミング:
  - トランジション: 0.5〜0.8秒
  - エレメント: 0.3〜0.5秒
  - 遅延: ステップごとに0.2〜0.3秒のインターバル
```

**アニメーション・ルール:**
- 1スライドあたり最大2つのアニメーション
- ヒーロー画像に動きをつけ、テキストはシンプルに
- 「彫刻の静止」×「装飾の動き」のコントラストを活用

### 被写体・要素の具体的指定

**メイン被写体:**
- ギリシャ・ローマ時代の大理石胸像（白基調）
- 姿勢：正面、ややアングルをつけたダイナミックなポーズ
- 表情：ニュートラルベース（アクセサリーで感情を付加）

**ポップアクセサリー（具体例）:**
| アクセサリー | 色 | 意味/文脈 |
|--------------|-----|----------|
| 丸サングラス | 黄色/虹色 | レトロポップ、70s |
| ヘッドフォン | オレンジ/ネオン | ミュージック、テクノ |
| 風船ガム | ピンク/赤 | アメリカンポップ |
| ソーダカップ | 緑/黄 | ファストフードカルチャー |
| VRヘッドセット | ブラック/LED | サイバーパンク |
| スマートフォン | ブラック | SNS、現代コミュニケーション |
| ベースボールキャップ | 各色 | ストリートカルチャー |

**画像処理スタイル:**
- 被写体は単色背景から完全に切り抜き（Isolate）
- リアルな3Dレンダリングまたは高品質フォトコラージュ
- 彫刻とアクセサリーの境界はシームレスに統合

### Slide 1: 表紙 / タイトル

**抽象的コンセプト:**
- "Invitation to Absurdity"（不条理への招待状）
- 観客の注意を即座に捉え、このプレゼンテーションの独特な世界観を提示

**具体的実装:**
```
レイアウト:     センター・ヒーロー（Center Hero）
背景色:       サンシャインイエロー (#F1C40F)
ヒーロー画像:  明るい黄色または虹色の丸サングラスをかけた
             大理石胸像が、ポップなカラーのソーダカップで飲む
タイトル:      画像に軽く重ねるよう配置
             フォント: Cooper Black / フォントサイズ: 80pt+
             色: 白 (#FFFFFF) / ブラックドロップシャドウ
サブタイトル:  タイトル下に小さく配置
             フォント: Helvetica Regular / 24pt
アニメーション:  タイトル: Bounce-in（0.5秒）
             サブタイトル: Fade-in（0.3秒、遅延0.2秒）
```

**意図された効果:**
- 黄色背景 + サングラス = レトロポップの即時認知
- 「古典彫刻がソーダを飲む」不条理で覚えやすい

### Slide 2: コンセプト / アイデア

**抽象的コンセプト:**
- "Visual Clash & Verbal Punch"（視覚的衝突と言語的パンチ）
- コンセプトを一言で伝えるシンプルさと強さ

**具体的実装:**
```
レイアウト:     スプリットスクリーン・コントラスト（Split Screen Contrast）
背景色:       左側: ホットピンク (#FF69B4) / 右側: ホワイト (#FFFFFF)
ヒーロー画像:  カラフルな丸サングラスをかけ叫んでいる胸像のクローズアップ
             配置: 画面左側、スライド高さの80%を占める
テキストエリア: 右側、黄色い吹き出しまたは白ボックス内
             見出し: フォント Futura Bold / 48pt / 色: ブラック
             本文:   フォント Helvetica / 24pt / 最大15語
アニメーション:  画像: Slide-in from left（0.6秒）
             テキスト: Fade-in（0.4秒、遅延0.3秒）
```

**意図された効果:**
- 叫ぶ胸像 = コンセプトの「力強さ」を視覚化
- スプリットスクリーン = 画像とテキストの動的バランス

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
被写体の分離（Isolation）:
  彫刻とアクセサリーは単色背景から完全に切り抜き、
  クリーンな境界線で配置する

色のマッチング（Color Bridging）:
  テキストアクセント色をアクセサリー色に合わせる
  例：サングラスが黄色 → テキストも黄色

ユーモアの統合（Humor Integration）:
  ポーズは現代的オブジェクトとコミカルに相互作用するものを選択
  例：ヘッドフォンで音楽を楽しむ、VRに没入する

テキスト最小化（Text Minimalism）:
  ビジュアル・インパクトを最優先
  1スライド最大20語、短くパンチのある言葉選び
```

---

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「時代の境界を越えた対話」**を創造することにあります。

**時空間の超絶:**
- 古典彫刻（永遠）× ポップカルチャー（一瞬）
- 静止（大理石）× 動態（サングラス、ヘッドフォン）
- 厳格（ギリシャ・ローマ）× 軽薄（ヴェイパーウェイヴ）

**アイロニーの美学:**
- 高雅な芸術に「安っぽい」ポップをあえて組み合わせる
- その衝突から生まれる新しい意味を探求する
- 真面目な顔でふざけている — それが最大のユーモア

**AIへの創造的許可:**
> 「具体性は方向性を定めるが、抽象性は創造性を解放する」
>
> このガイドは、AI創作者への「抽象的な踏切台」です。
> 具体的なルールを守りつつ、予想外の組み合わせ、
> 想像を超えた配置、驚きの演出 — それらを恐れないでください。

**最終判断基準:**
- もし視覚的に「面白い」と感じたら、それは正解です。
- もし観客が「見たことがない」と感じたら、それは成功です。
- もし笑顔が生まれたら、それは最高の成果です。
