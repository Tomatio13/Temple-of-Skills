# コンセプト: 「Analog Handmade（アナログ・ハンドメイド）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「紙の質感、手描きの揺らぎ、ハサミで切った断片の集まり」。デジタルの完璧さを拒否し、アナログな手作り感を愛でる — それは「Analog Handmade」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: アナログ、手作り、温かみ、emotional、authentic
- **Secondary Mood**: nostalgic（ノスタルジック）、imperfect（不完全）、wabi-sabi（侘び寂び）
- **Visual Tension**: 「デジタルの完璧さ」と「アナログの不完全さ」の矛盾

### デザイン哲学
- **Tactile Texture（触覚的な質感）**: 紙の凹凸、手描きの線、物理的な感覚
- **Imperfection Beauty（不完全の美）**: 揺れる線、歪んだ形、手作りの温かさ
- **Collage Aesthetics（コラージュ美学）**: 切り抜き、貼り付け、レイヤーの重ね
- **Wabi-Sabi Digital（デジタルの侘び寂び）**: 数字でありながら、アナログの魂を持つ

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  日本語: "しっぽいフォント Pro", "あんずもじ", "ニコモジ"※代替: "游明朝", "ヒラギノ明朝"
  英字:   "Caveat", "Patrick Hand", "Amatic SC", "Covered By Your Grace"
  特徴:   手書き風、筆文字、揺らぎのある線
  ウェイト: Regular (400) / Bold (700)
  サイズ:  H1: 56pt+ / H2: 44pt / H3: 32pt
  字間:   庅め（+3% 〜 +6%）

本文（BODY）:
  日本語: "游明朝", "ヒラギノ明朝 ProN", "Noto Serif JP"
  英字:   "Georgia", "Crimson Text", "Merriweather"
  特徴:   セリフフォント、温かみ、可読性重視
  ウェイト: Regular (400)
  サイズ:  14pt 〜 16pt
  行間:   1.8 〜 2.2（広め）

装飾テキスト:
  下線: 手描き風の波線
  マーカー: 蛍光ペン風（透明度30% 〜 50%）
  取り消し線: 手描き風の斜線
```

**タイポグラフィ・ルール:**
- 手書き風フォントを優先（見出し）
- セリフフォントで温かみを演出（本文）
- マーカー、下線で手書き感を追加
- 行間は広く、読みやすさを重視

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade: シンプルなフェード（0.8秒）
  - Cross Dissolve: クロスディゾルブ（1秒）
  - Page Turn: ページをめくるような効果（1.2秒）

エレメント・アニメーション（スライド内）:
  - Hand-write: 手書きで現れる（1.5秒、描画アニメーション）
  - Fade-in: ゆっくりと浮かび上がる（0.8秒）
  - Slide-up: 下から静かに現れる（0.6秒）
  - Float: 漂うように揺れる（2秒周期、紙片用）
  - Tape-apply: テープを貼るような効果（0.4秒）

タイミング:
  - トランジション: 0.8秒〜1.2秒（ゆったり）
  - エレメント: 0.6秒〜1.5秒
  - 遅延: ステップごとに0.3秒〜0.5秒の静かなインターバル
```

**アニメーション・ルール:**
- 動きは「ゆっくり」「静かに」「自然に」を心がける
- 急な動き、硬い動きは禁止
- 手書き、貼り付けなどのアナログな動きを再現
- 「人が作った」温かさを感じさせる

### 共通レイアウト・ルール

**紙の質感（Paper Texture）:**
```
和紙風:
  - 背景に微細な繊維質感
  - ノイズ: 標準偏差1〜2（非常に細かい）
  - 色味: ベージュ系（#EDE8DC）

クラフト紙風:
  - 粗い繊維質感
  - ノイズ: 標準偏差3〜4（やや粗い）
  - 色味: ライトブラウン（#D4C4B0）

トレーシングペーパー風:
  - 半透明（透明度80% 〜 90%）
  - 微細な凹凸
  - 用途: オーバーレイ、貼り付け効果
```

**テープとステープラー（Tapes & Staples）:**
```
マスキングテープ:
  - 幅: 12px 〜 20px
  - 色: 半透明のアースカラー
  - 角度: 斜めに貼る（±15度）
  - 位置: 要素の四隅、中央
  - 透明度: 70% 〜 85%

セロハンテープ:
  - 幅: 8px 〜 16px
  - 色: 完全な透明（透明度80% 〜 95%）
  - 光沢: 微細な反射
  - 位置: 小さな紙片の固定

ステープラー:
  - 幅: 4px 〜 6px
  - 色: シルバー（#C0C0C0）またはブラック（#2C2C2C）
  - 位置: 要素の左上、右上
  - 形状: 小さな矩形
```

**切り抜き効果（Cutout Effect）:**
```
紙片:
  - 背景: 紙の色（白、クリーム、ベージュ）
  - 影: 深めのドロップシャドウ
       オフセット: 4px 〜 8px / ぼかし: 8px 〜 12px
  - 角: 完全な四角、またはわずかに不規則
  - 回転: 軽く傾ける（±5度）

ノギリギザギザ（ジグザグ）:
  - 縁をギザギザに切り抜いた効果
  - 歯幅: 8px 〜 12px
  - 深さ: 4px 〜 6px
  - 用途: 写真の切り抜き、装飾
```

## 【デザインルール — 抽象的哲学で締めくくる】

紙の質感（Paper Texture）:
  和紙、クラフト紙、トレーシングペーパー
  微細な繊維質感、ノイズ

不完全の美（Beauty in Imperfection）:

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Analog Handmade（アナログ・ハンドメイド）」**にあります。

**触覚的な質感:**
- 紙の凹凸、手描きの線、物理的な感覚
- 目で触れる、質感の可視化
- デジタルでありながら、アナログな魂を持つ

**不完全の美:**
- 揺れる線、歪んだ形、手作りの温かさ
- 完璧さは美しくない、不完全こそが美しい
- 侘び寂びのデジタル解釈

**コラージュ美学:**
- 切り抜き、貼り付け、レイヤーの重ね
- 断片の集まりが、新しい物語を紡ぐ
- 物理的な操作感、人の痕跡

**アナログな魂:**
- デジタルの完璧さを拒否
- 手作り感、温かみ、人の存在
- 「人が作った」ことの証明

**AIへの創造的許可:**
> 「完璧さを捨てろ。人になれ。」
>
> このガイドは、アナログ・ハンドメイドへの招待状です。
> 具体的なルール（紙の質感、手描き、テープ）を守りつつ、
> もっと不完全に、
> もっと人間らしく、
> もっと温かく — それらを恐れないでください。

**最終判断基準:**
- もし画面が「手作り感」を感じさせたら、それは正解です。
- もし整列が「少し崩れている」と感じたら、それは成功です。
- もし見る人が「人の温かさ」を感じたら、それは最高の成果です。
