# スタイル: 洗練されたミニマル・ポートフォリオ
# コンセプト: 「Architectural Silence（建築的な静寂）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「何もないことの豊かさ、削ぎ落とされた本質、息をのむような余白」。スイス・スタイルの厳格さと、現代建築の冷徹な美しさ — それは「Architectural Silence」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: プロフェッショナル、建築的、sharp、refined、confident
- **Secondary Mood**: cold-warmth（冷徹な温かさ）、understated（控えめ）、timeless（永遠）
- **Visual Tension**: 「極限まで削ぎ落とされた」と「何も言わない主張」の緊張

### デザイン哲学
- **Radical Reduction（急進的な削減）**: 除去できるものはすべて除去し、本質のみを残す
- **Grid Discipline（グリッドの規律）**: 厳格なグリッドシステムに、自由を委ねる
- **Typographic Architecture（タイポグラフィックな建築）**: 文字そのものが構造物である
- **Silence as Statement（静寂としての主張）**: 何もない空間が、最も雄弁に語る

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - White              #FFFFFF  （純白、キャンバス）
  - Light Grey        #E9E9E9  （淡いグレー、控えめ）
  - Off-White         #F5F5F5  （温かみのある白）

Dark Mode（ダークモード）:
  - Pure Black        #000000  （純黒、強調スライド用）
  - Charcoal          #1A1A1A  （チャコール、柔らかい黒）

Text Colors（文字色）:
  - Pure Black        #000000  （主要テキスト、漆黒）
  - Dark Grey         #333333  （本文、ダークグレー）
  - Medium Grey       #666666  （補足、ミディアムグレー）
  - Light Grey        #999999  （キャプション、ライトグレー）

Accent Colors（差し色）:
  - Single Black      #000000  （黒一色で統一、太い線や強調文字に）
  - 色は使用しない、または極めて控えめに（1ポイントのみ）
```

**配色ルール:**
- 基本はモノクローム（白、グレー、黒のみ）
- アクセント色は原則使用しない、必要なら黒一色で統一
- ダークモードは「強調したいスライド」のみで使用、対比効果を狙う
- 1スライドあたり最大2色（背景＋文字）

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  英字:   "Helvetica Now", "Inter", "SF Pro Display"
  特徴:   サンセリフ、幾何学的、グロタルスク
  ウェイト: Bold (700) / ExtraBold (800)
  サイズ:  H1: 64pt+ / H2: 48pt / H3: 32pt
  配置:   装飾的に、場合によっては回転

本文（BODY）:
  日本語: "Noto Sans JP", "ヒラギノ角ゴ ProN", "游ゴシック"
  英字:   "Inter", "Roboto", "SF Pro Text"
  特徴:   クリーン、可読性重視、ウェイト300-400
  サイズ:  14pt 〜 18pt（小さく）
  字間:   庅め（+2% 〜 +5%）
  行間:   広め（1.8 〜 2.2）

セクション番号（SECTION NUMBERS）:
  フォント: Helvetica Now / Inter / 14pt 〜 16pt
  スタイル: "01. INTRODUCTION" の形式
  配置:   すべてのスライドの左上または右上
```

**タイポグラフィ・ルール:**
- 英語見出しは太字で装飾的に配置、日本語は控えめに
- 文字サイズは極小、字間と行間を広く取り、高級感を演出
- セクション番号は全スライドに配置、一貫性を維持
- 行揃えは左揃え基本、場合によっては中央揃え

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade: 最もシンプル、推奨（0.5〜0.8秒）
  - Slide: 横からのスライド（0.4〜0.6秒）
  - Cut: 瞬時の切り替え（最もミニマル）

エレメント・アニメーション（スライド内）:
  - Fade-in: ゆっくりと浮かび上がる（0.6〜1秒）
  - Slide-up: 下から静かに現れる（0.5〜0.8秒）
  - Scale-in: 拡大しながら現れる（0.6秒）
  - Sequential: 順次現れる（要素ごとに0.2〜0.3秒の遅延）

タイミング:
  - トランジション: 0.5〜0.8秒（ゆったり、落ち着いて）
  - エレメント: 0.5〜1秒
  - 遅延: ステップごとに0.2〜0.3秒の静かなインターバル
```

**アニメーション・ルール:**
- 動きは「最小限」「静かに」「上品」を心がける
- バウンス、回転、揺れは一切禁止
- フェードとスライドのみを使用、シンプルさを維持
- 「何も起きていないように見える」くらいの繊細さ

---

### 共通レイアウト・ルール

**ナビゲーション（Navigation）:**
```
セクション番号:
  形式: "01. INTRODUCTION" の形式
  フォント: Inter / 14pt / 色: ダークグレー (#333333)
  配置: すべてのスライドの左上（または右上）
  位置: 上端から24px、左端から24px
```

**グリッドシステム（Grid System）:**
```
基本グリッド:
  - カラム数: 12列
  - ガーター: 24px
  - マージン: 左右48px、上下64px
  - 整列: すべての要素はグリッドに従う

厳格な整列:
  - 要素の端を揃える（Left alignment basic）
  - 垂直方向のリズムを意識
  - 中央配置は計算された対称性で
```

**余白の美学（Whitespace as Luxury）:**
```
ネガティブスペース:
  - 「何もない」空間を意図的に配置する
  - マージンは最小64px、理想的には96px以上
  - 要素同士の間隔に「高級感」を感じさせる

Less is More:
  - 1スライドあたりの要素を最小限に
  - 余白を怖がらず、大胆に空ける
  - 情報は詰め込みすぎず、選別する
```

### Layout 1: タイトル・タイポグラフィ

**抽象的コンセプト:**
- "Typographic Monument"（タイポグラフィックな記念碑）
- 文字そのものが構造物、視覚的な錨

**具体的実装:**
```
レイアウト:     タイトル・タイポグラフィ（Title Typography）
背景色:       ホワイト (#FFFFFF)
セクション番号: 左上に "01. INTRODUCTION"
             フォント: Inter / 14pt / 色: ダークグレー
タイトル:      中央に配置、小さく太く
             フォント: Helvetica Now Bold / 48pt 〜 64pt / 色: ブラック
             行間: 1.1 / 詰め気味
散布要素:     受賞バッジ、キーワードをスタンプのようにランダム配置
             形状: 円形、角丸四角、自由曲線
             サイズ: 16px 〜 32px
             色: ブラック単色、またはグレースケール
             配置: タイトル周囲、非対称に3〜5個
サブテキスト:   極小サイズで補足
             フォント: Inter / 14pt / 色: ミディアムグレー
             配置: タイトル下または右下
アニメーション:  タイトル: Fade-in（0.8秒）
             散布要素: 順次 Fade-in（0.3秒間隔、ランダム）
             サブテキスト: Fade-in（0.5秒、遅延0.4秒）
```

**意図された効果:**
- 小さく太いタイトル = 控えめな主張、自信の表れ
- 散布要素 = 視覚的なリズム、ランダム性による魅力
- 広大な余白 = 高級感、本質への集中

### Layout 2: テキスト＋データ強調

**抽象的コンセプト:**
- "Asymmetric Balance"（非対称な均衡）
- 左右の対比で、情報に物語を与える

**具体的実装:**
```
レイアウト:     テキスト＋データ強調（Text + Data Emphasis）
背景色:       ホワイト (#FFFFFF) または ライトグレー (#E9E9E9)
セクション番号: 左上に "02. DATA"
分割:         非対称の分割（左40%:右60% または 左60%:右40%）
左側（テキスト）:
             物語るようなテキストブロック
             見出し: フォント Inter Bold / 24pt 〜 32pt / 色: ブラック
             本文:   フォント Noto Sans JP / 16pt / 色: ダークグレー
                     行間2.0 / 最大100語
             配置: 左寄せ、上から35%の位置
区切り線:      垂直線、極細（1px）または太い（4px）
             色: ブラック / 位置: 分割境界
右側（データ）:
             巨大な数字
             フォント: Helvetica Now / 96pt 〜 144pt / 色: ブラック
             配置: 中央揃えまたは右寄せ
             サフィックス: % / 年 / 件などは24ptで小さく添える
アニメーション:  左側: Fade-in + Slide-up（0.8秒）
             区切り線: Draw-vertical（0.6秒、上から下へ）
             数字: Fade-in（1秒、遅延0.3秒）
```

**意図された効果:**
- 非対称分割 = 動的なバランス、視線の誘導
- 巨大な数字 = インパクト、記憶に残る視覚的要素
- 極細の区切り線 = 上品な分離、余白の活用

### Layout 3: カードグリッド

**抽象的コンセプト:**
- "Ordered Variety"（秩序ある多様性）
- 厳格なグリッドの中に、個性を配置

**具体的実装:**
```
レイアウト:     カードグリッド（Card Grid）
背景色:       ホワイト (#FFFFFF)
セクション番号: 左上に "03. WORKS"
グリッド:      隙間の狭いグリッド配置
             カラム: 3列 または 4列
             ギャップ: 16px 〜 24px（狭め）
カード:        高品質な画像を並べる
             サイズ: 正方形または4:3の矩形
             角丸: なし（完全な四角）または4px
             枠線: なし、または極細（1px）のブラック
オーバーレイ:   画像の上に文字が現れるWeb的な表現
             ホバー時: 黒の半透明レイヤー（透明度70%）
             テキスト: 白文字、見出し18pt / 説明14pt
タイトル:      グリッドの上または下に小さく配置
             フォント: Inter Bold / 16pt 〜 20pt / 色: ブラック
             配置: 左寄せ、グリッドと一体化
アニメーション:  各カード: 順次 Fade-in（0.2秒間隔、左上から右下へ）
             オーバーレイ: ホバー時 Fade-in（0.3秒）
```

**意図された効果:**
- 隙間の狭いグリッド = 密度感、プロフェッショナルな印象
- 高品質な画像 = 作品の質を視覚的に伝達
- オーバーレイ = インタラクティブな遊び心、情報の階層化

### Layout 4: 全画面グラフィック

**抽象的コンセプト:**
- "Atmospheric Immersion"（雰囲気への没入）
- 画像そのものがスライド、言葉は余白に息づく

**具体的実装:**
```
レイアウト:     全画面グラフィック（Full-Screen Graphic）
背景画像:     画面全体（または半分以上）にオフィスの内観写真
             被写体: コンクリート打ちっぱなし、Macが並ぶデスク、建築的空間
             トーン: 彩度を落とし、クールに（彩度20%以下）
             位置: 画面を完全に覆う、または左側に70%配置
キャプション:   極小サイズのテキスト
             フォント: Inter / 12pt 〜 14pt / 色: ホワイトまたはブラック
             内容: プロジェクト名、年、簡単な説明
             配置: 左下または右下、端から24px
             最大2行
セクション番号: 反対色で小さく配置
             例: 黒背景なら白文字
アニメーション:  背景画像: Slow Fade-in（1.5秒）
             キャプション: Fade-in（0.8秒、遅延0.5秒）
```

**意図された効果:**
- 全画面画像 = 没入感、視覚的インパクト
- 彩度を落とす = クールさ、プロフェッショナリズム
- 極小キャプション = 控えめな情報提示、画像の邪魔をしない

### Layout 5: 写真＋リスト分割

**抽象的コンセプト:**
- "Visual Narrative Split"（視覚的物語の分割）
- 左右の対比で、情報にリズムを与える

**具体的実装:**
```
レイアウト:     写真＋リスト分割（Photo + List Split）
背景色:       ホワイト (#FFFFFF)
セクション番号: 左上に "05. ABOUT"
分割:         50:50の均等分割
左側（写真）:
  建築的・抽象的な写真
  トーン: 彩度を落とし、モノクロに近い
  サイズ: 画面左半分を完全に覆う
  時に cropping で大胆なトリミング
右側（リスト）:
  データリスト形式
  各項目:
    項目名（英語）: フォント Inter Bold / 18pt / 色: ブラック
    内容（日本語）: フォント Noto Sans JP / 16pt / 色: ダークグレー
  行間: 2.0（広め）
  最大6項目
  配置: 左寄せ、上から35%の位置
  マージン: 左右48px、上下64px
アニメーション:  写真: Fade-in（1秒）
             各項目: 順次 Fade-in（0.3秒間隔、上から下へ）
```

**意図された効果:**
- 50:50分割 = 対比、バランス、視線の水平移動
- 建築的な写真 = プロフェッショナル、洗練された印象
- 広い行間 = 高級感、読みやすさ、情報の選別

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
厳格なグリッド（Strict Grid）:
  すべての要素は12列のグリッドシステムに従う
  整列を意識し、ランダム性を排除する
  垂直方向のリズムを維持する

余白の極大化（Maximal Whitespace）:
  1スライドあたりの要素を最小限にする
  マージンは最小64px、理想的には96px以上
  「何もない」空間を恐れない

色の単純化（Color Simplicity）:
  基本はモノクローム（白、グレー、黒のみ）
  アクセント色は原則使用しない
  必要なら黒一色で統一する

ナビゲーションの一貫性（Consistent Navigation）:
  すべてのスライドにセクション番号を配置
  位置、フォント、色を統一する
  観客の位置を常に認識させる
```

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Architectural Silence（建築的な静寂）」**にあります。

**急進的な削減:**
- 除去できるものはすべて除去し、本質のみを残す
- 「足りない」と思う余白が、実は「十分」である
- デザインとは「削る」ことであり、「足す」ことではない

**グリッドの規律:**
- 厳格なグリッドシステムに、自由を委ねる
- 整列は美しさの基本、秩序は安心感を生む
- ルールを守ることで、創造性は輝く

**タイポグラフィックな建築:**
- 文字そのものが構造物である
- 見出しは梁、本文は壁、余白は窓
- 文字の配置が、空間を構築する

**静寂としての主張:**
- 何もない空間が、最も雄弁に語る
- 「何も言っていない」ように見えて、「すべてを言っている」
- 控えめな主張が、最大のインパクトを持つ

**AIへの創造的許可:**
> 「完璧を追うな、本質を追え。」
>
> このガイドは、極限まで削ぎ落とされた美学への招待状です。
> 具体的なルール（グリッド、余白、色）を守りつつ、
> もっと削れる余地、
> もっと空けられる空間、
> もっと静かに語る方法 — それらを恐れないでください。

**最終判断基準:**
- もし画面が「静寂をたたえている」と感じたら、それは正解です。
- もし余白が「主役」と感じたら、それは成功です。
- もし見る人が「息をのむ」と感じたら、それは最高の成果です。
