# スタイル: ストーン＆グラス・マテリアル / 建築的モダン / 重厚
# コンセプト: 「Material Gravity（マテリアル・グラビティ）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「石の冷たさとガラスの透明さが交差する、重厚な物質世界」。コンクリートの打ちっぱなし、大理石の模様、すりガラスの曖昧さ — それは「Material Gravity」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: 静謐、堅牢、未来的、高級感、weighty、solid
- **Secondary Mood**: tactile（触覚的）、atmospheric（雰囲気的）、permanent（永続的）
- **Visual Tension**: 「不変の重さ」と「透明な軽さ」の物質的対比

### デザイン哲学
- **Tactile Materiality（触覚的な物質性）**: 目で触れる、質感の可視化
- **Glassmorphism（グラスモーフィズム）**: すりガラスのような半透明レイヤーで情報の階層化
- **Architectural Lighting（建築的なライティング）**: 自然光が差し込んだような、柔らかくリアルな陰影
- **Monumental Silence（記念碑的な静寂）**: 石碑のような不変性、永遠を感じさせる重厚さ

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - Cool Grey         #E0E0E0  （クールグレー、コンクリート風）
  - Stone Black       #1A1A1A  （ストーンブラック、玄武岩）
  - Marble White      #F5F5F0  （大理石白、温かみ）
  - Slate Grey        #708090  （スレートグレー、粘板岩）

Text Colors（文字色）:
  - Matt Black        #000000  （マットブラック、吸光）
  - Matt White        #FFFFFF  （マットホワイト、純白）
  - Stone Grey        #4A4A4A  （ストーングレー、中間色）

Accent Colors（差し色）:
  - Copper            #B87333  （銅、暖かみのあるメタル）
  - Brass             #B5A642  （真鍮、金色がかったメタル）
  - Steel Blue        #4682B4  （鋼青、冷たいメタル）

Metallic Gradients（メタリック・グラデーション）:
  - Copper Gradient:  #B87333 → #D4A574
  - Brass Gradient:   #B5A642 → #E5C585
  - Steel Gradient:   #708090 → #A9A9A9
```

**配色ルール:**
- 基本はモノクローム＋メタリックの2層構造
- 蛍光色・ビビッドな色は一切禁止
- メタリックカラーはグラデーションで「光沢」を表現
- 1スライドあたり最大2色（背景＋メタリックアクセント1色）

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```

  英字:   "Futura Bold", "Gilroy ExtraBold", "SF Pro Display Black"
  日本語: "ヒラギノ角ゴ Std W8", "Noto Sans JP Black"
  特徴:   彫刻のような太さ、幾何学的サンセリフ
  ウェイト: ExtraBold (800) / Black (900)
  サイズ:  H1: 72pt+ / H2: 56pt / H3: 40pt
  字間:   詰め（-2% 〜 -5%）

本文（BODY）:
  英字:   "Inter", "Roboto", "SF Pro Text"
  日本語: "Noto Sans JP Light", "ヒラギノ角ゴ ProN Light"
  特徴:   細身、クリーン、可読性重視
  ウェイト: Light (300) / Regular (400)
  サイズ:  14pt 〜 16pt（非常に小さく）
  行間:   1.8 〜 2.2（広め）

型押し効果（DEBOSS EFFECT）:
  使用:   見出しや強調文字
  構成:   文字が「凹んだ」ような影
  設定:   影オフセット(2px, 2px) / ブラケット0px / 不透明度30%
```

**タイポグラフィ・ルール:**
- 見出しは超太字、字間を詰め、彫刻的なインパクト
- 本文は極小サイズ、行間を広く取り、空間の広さを強調
- 型押し（デボス）効果で「石に刻まれた」質感を演出
- 行揃えは左揃え基本、タイトルのみ中央揃え可

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fade: シンプルなフェード（0.8〜1秒）
  - Slow Zoom: ゆっくりとしたズーム（1秒）
  - Cross Dissolve: クロスディゾルブ（1.2秒）

エレメント・アニメーション（スライド内）:
  - Fade-in: ゆっくりと浮かび上がる（0.8〜1.2秒）
  - Slide-up: 下から静かに現れる（0.6〜1秒）
  - Materialize: 物質が実体化するように（1秒）
  - Glow-in: 光が灯るように（強調ポイント、0.6秒）
  - Reflect-in: 光の反射が走る（メタリック要素、0.8秒）

タイミング:
  - トランジション: 0.8〜1.2秒（ゆったり、重厚に）
  - エレメント: 0.6〜1秒
  - 遅延: ステップごとに0.3〜0.5秒の静かなインターバル
```

**アニメーション・ルール:**
- 動きは「ゆっくり」「重厚に」「質量感を伴って」を心がける
- バウンス、軽快な動きは一切禁止
- 光と影のアニメーションを活用（Glow、Reflect）
- 「重いものが動く」ような重量感を維持

### 素材感（テクスチャ）の具体的実装

**背景テクスチャ（Background Textures）:**
```
コンクリート（Concrete）:
  - 打ちっぱなしの質感
  - 色味: クールグレー (#E0E0E0) ベース
  - ノイズ: 微細な粒子感（標準偏差2〜4）
  - コントラスト: ソフト（±20%）

大理石（Marble）:
  - 白基調に薄いグレーの脈
  - 色味: マーブルホワイト (#F5F5F0) ベース
  - 模様: 不規則な曲線の脈（透明度10〜20%）
  - 深さ: 奥行きを感じさせる

スレート（Slate）:
  - 粘板岩の層状構造
  - 色味: スレートグレー (#708090) ベース
  - 模様: 水平方向の細い線（1px以下）
```

**すりガラス効果（Frosted Glass / Glassmorphism）:**
```
グラス・カード:
  背景フィルター: blur(10px 〜 20px)
  塗り: 白または黒（透明度60% 〜 80%）
  枠線: 極細の白または黒（1px、透明度20%）
  影: 深めのドロップシャドウ（オフセット8px、ぼかし16px、不透明度30%）

配置:
  カード同士の間隔: 32px 〜 48px
  重ね順: 背景写真 → ガラスカード → テキスト
```

**光と影（Lighting & Shadow）:**
```
物理法則（Physical Laws）:
  光源: 左上から（45度の角度）
  一貫性: すべての要素で影の方向を統一
  ハイライト: 左上端に明るい部分
  シャドウ: 右下端に暗い部分

厚み表現（Depth）:
  側面の色: 表面より20%暗い色
  影の色: ブラック（不透明度20% 〜 40%）
  ぼかし: 4px 〜 16px（要素のサイズに比例）
```

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
物理法則（Physical Laws）:
  光源は左上から（45度の角度）と想定する
  すべての要素で影の方向を一貫させる
  ハイライトとシャドウを矛盾なく配置する

厚みの表現（Depth Perception）:
  要素には「厚み」を感じさせる処理を施す
  側面の色を変える（表面より20%暗く）
  深めの影で地面との接続を表現

質感の統一（Texture Consistency）:
  一つのスライドで使用するテクスチャは最大2種類
  コンクリート + すりガラス、大理石 + 金属など
  異なる素材の組み合わせに「調和」を持たせる

色の抑制（Color Restraint）:
  メタリックカラーはアクセントとして使用
  蛍光色、ビビッドな色は一切禁止
  全体に落ち着いたトーンを維持する
```

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Material Gravity（マテリアル・グラビティ）」**にあります。

**触覚的な物質性:**
- 目で触れる、質感の可視化
- 石の冷たさ、ガラスの滑らかさ、金属の硬さ
- デジタルでありながら、アナログな物質世界を再現

**グラスモーフィズム:**
- すりガラスのような半透明レイヤー
- 情報の階層化、視覚的な深度
- 「見えそうで見えない」曖昧さの美しさ

**建築的なライティング:**
- 自然光が差し込んだような、柔らかくリアルな陰影
- 光と影の対比で、物質の存在感を強調
- 暗闇の中に灯る光の劇的さ

**記念碑的な静寂:**
- 石碑のような不変性、永遠を感じさせる重厚さ
- 変わらないもの、時を超えるもの
- 「言葉を刻む」ことの重み

**AIへの創造的許可:**
> 「物質を感じさせよ。重さを、冷たさを、光の温もりを。」
>
> このガイドは、物質世界への招待状です。
> 具体的なルール（テクスチャ、光、影）を守りつつ、
> 触れたくなるような質感、
> 存在感を放つ厚み、
> 見る人が「石の重さ」を感じるようなリアリズム — それらを恐れないでください。

**最終判断基準:**
- もし画面が「重厚さ」を感じさせたら、それは正解です。
- もし質感が「触れそう」と感じたら、それは成功です。
- もし見る人が「石の冷たさ」を感じたら、それは最高の成果です。
