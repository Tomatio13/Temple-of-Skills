# スタイル: スポーツ / アスレチック / エナジー
# コンセプト: 「Kinetic Energy（運動エネルギー）」

---

## 【抽象的指示 — AIの創造性を解放する】

### 核心的コンセプト
「疾走する風、鼓動のようなリズム、勝利への渇望」。スポーツの瞬間を切り取ったような動的なエネルギー — それは「Kinetic Energy」にあります。

### 感情的トーン＆ムード
- **Primary Mood**: 情熱的、スピーディ、力強い、競争心、dynamic、urgent
- **Secondary Mood**: aggressive（攻撃的）、triumphant（凱旋）、raw（原初的）
- **Visual Tension**: 「静」と「動」の境界を越えた、瞬間の爆発

### デザイン哲学
- **Diagonal Dynamics（斜めの力動）**: 水平・垂直を拒み、斜めのラインで運動エネルギーを視覚化
- **Motion Blur（モーションブラー）**: 「速すぎて見えない」をあえて表現する
- **Competitive Dichotomy（競争的な二項対立）**: VSの構図、勝者と敗者の明確な境界
- **Adrenaline Typography（アドレナリン・タイポグラフィ）**: 文字そのものが走る、叫ぶ、燃える

## 【具体的指示 — 方向性をコントロールする】

### 3つのデザイン要素

#### 1. カラー（COLOR）

**パレット構成:**
```
Base Backgrounds（背景色）:
  - Asphalt Black    #111111  （アスファルトのような黒）
  - Deep Charcoal    #0A0A0A  （深いチャコール）
  - Night Navy       #0D1B2A  （夜のネイビー）

Text Colors（文字色）:
  - Pure White       #FFFFFF  （純白）
  - Electric White   #F0F8FF  （電光のような白）

Accent Colors（差し色）:
  - Volt Lime        #CCFF00  （ボルトライム、鮮烈な黄緑）
  - Neon Orange      #FF4500  （ネオンオレンジ、燃えるような橙）
  - Electric Cyan    #00FFFF  （電気シアン、冷たい輝き）
  - Hot Magenta      #FF10F0  （熱いマゼンタ）

Gradient Overlays（グラデーション・オーバーレイ）:
  - Fade to Black:   黒（不透明度100%）→ 透明（0%）
  - Fade to Accent:  アクセント色 → 透明
  - 用途: 写真の上に重ね、テキストを読みやすくする
```

**配色ルール:**
- 背景は基本暗色（黒、チャコール、ネイビー）
- アクセントはビビッドなネオンカラーでエネルギーを表現
- グラデーションは「黒→透明」「アクセント→透明」の2パターン
- 1スライドあたり最大2色（暗い背景＋ネオンアクセント1色）

---

#### 2. タイポグラフィ（TYPOGRAPHY）

**フォント構成:**
```
見出し（HEADINGS）:
  英字:   "Impact", "Din Condensed", "Anton", "Teko"
  日本語: "Hiragino Sans Std W8", "Noto Sans JP Black"
  特徴:   斜体（Italic）、極太ゴシック、凝縮された文字幅
  ウェイト: Black (900) / UltraBold
  スタイル: Italic（斜体）を基本
  傾き:   -10度 〜 -20度の skew

本文（BODY）:
  英字:   "Inter Italic", "Roboto Italic", "Open Sans Italic"
  日本語: "Noto Sans JP", "ヒラギノ角ゴ ProN"
  特徴:   サンセリフ、斜体、流動的
  ウェイト: Regular (400) 〜 Bold (700)
  スタイル: Italic（斜体）

数字（NUMBERS）:
  スタイル: 背番号のようなステンシルフォント
  フォント: "Teko", "Anton Condensed", "Stencil Std"
  特徴:   極太、縦長、アスレチック
  サイズ:  48pt 〜 96pt（強調時は更大）
```

**タイポグラフィ・ルール:**
- 見出しは斜体＋極太、運動エネルギーを視覚化
- 本文も斜体で統一、画面全体が「走っている」感覚
- 数字はステンシル風、背番号のようなアイコニックな表現
- 文字を傾ける（skew -10〜-20度）で加速感を出す

---

#### 3. アニメーション（ANIMATION）

**アニメーション構成:**
```
トランジション（スライド間）:
  - Fast Slide: 横からの高速スライド（0.3〜0.5秒）
  - Zoom Flash: ズームしながら遷移（0.4秒）
  - Cut: 瞬時の切り替え（最もスピーディ）

エレメント・アニメーション（スライド内）:
  - Slash-in: 斜めに勢いよく現れる（0.3秒）
  - Blur-in: ブレしながら現れる（0.4秒）
  - Punch-in: 打撃のように現れる（0.2秒）
  - Shake: 揺れる（強調、0.5秒）
  - Pulse-Flash: 明滅+フラッシュ（緊急性、0.3秒）

タイミング:
  - トランジション: 0.3〜0.5秒（テンポよく、スピーディ）
  - エレメント: 0.2〜0.4秒
  - 遅延: ステップごとに0.1〜0.2秒の攻めたインターバル
```

**アニメーション・ルール:**
- 動きは「速く」「鋭く」「力強く」を心がける
- スローモーションは基本禁止、リアルタイムのスピード感
- ブラー、振動、フラッシュを活用し、運動エネルギーを表現
- 「早すぎて見えない」感覚を演出

### 共通レイアウト・ルール

**ナビゲーション（Navigation）:**
```
斜めカット・シェイプ:
  形状: 平行四辺形、長方形を斜めにカット
  傾き: -15度 〜 -30度（右上がり）
  サイズ: 幅80px 〜 120px / 高さ32px 〜 48px
  塗り: アクセント色（ボルトライム、ネオンオレンジ）
  配置: 画面の右上または左上
  中の文字: ページ番号、スコア、タイム
```

**シェイプ（Shapes）:**
```
斜めの傾斜（Skew）:
  長方形、画像、テキストブロックを斜めに傾ける
  傾き: -10度 〜 -20度（skew transform）
  用途: 運動エネルギー、スピード感の演出

平行四辺形:
  形状: 左右が平行でない四角形
  用途: テキストコンテナ、画像フレーム
  傾き: -15度 〜 -30度

ギザギザ線:
  形状: 雷のようなジグザグ
  用途: VSの区切り、境界線
  太さ: 4px 〜 8px
```

### Layout 1: アクション・カット

**抽象的コンセプト:**
- "Frozen Motion"（凍結された動き）
| 瞬間のスピードを、静止画で切り取る

**具体的実装:**
```
レイアウト:     アクション・カット（Action Cut）
背景:         動きのある写真（ブレ感のあるもの）
             被写体: 走る選手、跳ぶ瞬間、ゴールの瞬間
             ブレ: 故意的なモーションブラー
             彩度: +20%〜+30%（鮮やかに強調）
オーバーレイ:   写真の上に黒から透明へのグラデーション
             方向: 下から上、または左から右
             割合: 画面の30%〜50%を黒で覆う
タイトル:      手前に大きく斜体の文字を配置
             フォント: Impact Italic / 72pt+ / 色: ホワイト
             傾き: skew(-15度)
             位置: 写真の人物と文字を一部重ねる
             効果: ドロップシャドウ（オフセット4px、ぼかし0px）
サブテキスト:   タイトルの下に小さく
             フォント: Inter Italic / 24pt / 色: 電光シアン
ナビゲーション: 右上に斜めカットシェイプ
             塗り: ボルトライム (#CCFF00)
             中の文字: "01" / フォント: Teko / 20pt
アニメーション:  背景: Fast Slide-in（0.4秒）
             タイトル: Slash-in（0.3秒、斜めに勢いよく）
             サブテキスト: Blur-in（0.3秒、遅延0.1秒）
```

**意図された効果:**
- ブレのある写真 = スピード感、リアルタイムの動き
- 文字と写真の重ね = 臨場感、没入感
- 斜体タイトル = 加速、運動エネルギー

## 【デザインルール — 抽象的哲学で締めくくる】

### 具体的実装ルール
```
斜めの力動（Diagonal Dynamics）:
  すべての要素は水平・垂直を避ける
  長方形、画像、テキストを斜めに傾ける
  平行四辺形、ギザギザ線を活用する

運動エネルギー（Kinetic Energy）:
  静止画であっても「動いている」感覚を演出
  ブレ、振動、傾斜を活用する
  文字は斜体（Italic）を基本とする

スピード感（Speed Perception）:
  アニメーションは速く、鋭く、力強く
  テンポよく、攻めたインターバル
  「早すぎて見えない」感覚を恐れない

ネオン・コントラスト（Neon Contrast）:
  暗い背景にビビッドなアクセントを配置
  グロー効果で「発光」感を出す
  電光、ネオン、ボルトライムを積極的に使用
```

### 抽象的デザイン哲学

このスタイルガイドの本質は、**「Kinetic Energy（運動エネルギー）」**にあります。

**斜めの力動:**
- 水平・垂直は「静止」を意味する
- 斜めのラインは「動き」を象徴する
- 重力に抗って走る、飛ぶ、勝利する

**モーション・ブラー:**
- 「速すぎて見えない」をあえて表現する
- ブレは失敗ではなく、スピードの証
- 静止画の中に、運動の瞬間を凍結

**競争的な二項対立:**
- VSの構図、勝者と敗者の明確な境界
- 雷のようなギザギザ線が、決定的な分割
- スポーツは競争であり、デザインもまた

**アドレナリン・タイポグラフィ:**
- 文字そのものが走る、叫ぶ、燃える
- 斜体は「加速」の視覚的表現
- 極太フォントは「力強さ」の象徴

**AIへの創造的許可:**
> 「静止を破れ。動きを演出せよ。」
>
> このガイドは、スポーツの瞬間への招待状です。
> 具体的なルール（斜め、スピード、コントラスト）を守りつつ、
> もっと速く、
> もっと鋭く、
> もっと激しく — そのスピードに限度はない。

**最終判断基準:**
- もし画面が「走っている」と感じたら、それは正解です。
- もし見る人の「心拍数が上がった」と感じたら、それは成功です。
- もしプレゼンテーションが「試合会場」になったら、それは最高の成果です。
