# GitHub Starred Repository Activity

GitHubのスター付きリポジトリ更新チェッカーです。最新のコミットやリリース内容を日本語で概要表示します。

## 前提

- `gh` (GitHub CLI) がインストール済みで、`gh auth login` 済みであること
- `bash` と GNU `date` が使えること

## 実行手順

### 1. スキルディレクトリの特定

この `SKILL.md` の親ディレクトリをスキルディレクトリとして扱い、そこで実行してください。

### 2. 更新状況の取得

スキルディレクトリで `scripts/stars_activity.sh` を実行します。

```bash
bash scripts/stars_activity.sh [YYYY-MM-DD] [--json] [--releases-only] [--limit=N]
```

- 引数なし: 2日前から現在まで
- `YYYY-MM-DD`: 指定日以降
- `--releases-only`: リリースがあったリポジトリのみに絞る
- `--limit=N`: 表示件数をN件に制限
- `--json`: JSON形式で出力

リポジトリ数が多い場合は、`--json` または `--releases-only` を使って出力量を抑えてください。

### 3. 更新概要の生成

スクリプト出力を読み取り、JST日時、リポジトリ名、リリースタグ、変更概要を最新順で出してください。

```text
2026/05/28 06:04  google-gemini/gemini-cli [v0.45.0-preview.0]
  → vimの未マップキー無視、MCPブラックリストバイパス修正、PTYリサイズエラー抑制の3つのバグ修正

2026/05/28 05:22  Mintplex-Labs/anything-llm [v1.13.0]
  → v1.13.0リリース。CerebrasをLLMプロバイダーとして追加
```

### 4. おすすめのハイライト

更新内容からユーザーの関心が高そうなリポジトリを3〜5件ピックアップしてください。
候補が3件未満の場合は全件を提示してください。

- 機能追加、メジャーバージョンアップ、セキュリティ修正を優先
- 各リポジトリについて「なぜおすすめか」を1文で添える

## 出力ルール

- **日本語で出力**: 更新概要はすべて日本語
- **要約重視**: コミットメッセージを羅列せず、変更の意図を簡潔に表現
- **時系列順**: 最新の更新から順に表示
- **リリース強調**: 新しいバージョンタグがある場合は明記
- **セキュリティ修正**: セキュリティ関連の修正があれば優先的にハイライト
- **失敗理由の明示**: `gh api` の失敗やレート制限が疑われる場合は、結果の前に原因候補を明記
