# データソース
以下のJSONファイルからデータを読み込んで、日報を作成してください：
`{{DATA_PATH}}`

JSON構造：
- `date`: 日付
- `entries_count`: 総エントリ数
- `projects_count`: 活動プロジェクト数
- `git_totals`: 総コミット数、追加/削除行数、変更ファイル数
- `projects`: プロジェクト別のデータ（コミット数、エントリ詳細など）
- `entries`: 全エントリの詳細（時間、プロジェクト、表示名）

# 構成ルール
1. **プロジェクト名**: `ディレクトリ名（プロジェクトの役割や通称）`という形式で、人間が直感的に理解できるように記載。
2. **学びの言語化**: 単なる事実（〜を習得）だけでなく、「〜ができるようになり便利になった」「〜という発見があった」という体験ベースの表現にする。
3. **参照URLの集約**: 作業中に参照したドキュメントやリポジトリのURLを、末尾にリストアップする。
