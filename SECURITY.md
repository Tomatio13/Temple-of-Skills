# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by opening a private security advisory on GitHub:

1. Go to **Security** → **Report a vulnerability**
2. Provide a clear description of the issue and steps to reproduce

Please do not publicly disclose the vulnerability until a fix has been released.

## Supported Versions

Only the latest version on the `main` branch is supported with security updates.
