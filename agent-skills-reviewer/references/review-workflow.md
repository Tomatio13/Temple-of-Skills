# レビュー手順

## 手順

1. 指定された `SKILL.md`、未指定ならカレントの `SKILL.md` を対象にする。
2. frontmatter、見出し、本文、直接リンクされた参照を読む。欠落したリンクは記録する。
3. [quality-rubric.md](quality-rubric.md) の全項目を、行番号または見出しとともに判定する。
4. `critical` を先に判定してから、通常の改善点を優先度順に整理する。
5. [output-contract.md](output-contract.md) に従って結果を作る。

## 例外と矛盾

- 対象が読めない場合は、対象パスまたはアクセス権を確認して監査を止める。
- 直接参照が欠ける場合は影響を指摘し、内容を推測しない。
- 外部ツール、権限、サービスの実在を確認できない場合は `要確認` とする。
- 対象 `SKILL.md`、直接参照、README等の順に扱い、解消不能なら `要確認` にする。

## 完了条件

- 対象と確認範囲を明示した。
- 各重大指摘に根拠と修正方針がある。
- 情報不足、壊れた参照、未解決の矛盾を明示した。
- 固定の出力契約に従った。
