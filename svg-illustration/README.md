# SVG Illustration

Marp/Marpit スライド向けのクリーンで編集可能なSVG図を作成するためのルールとパターンを提供するスキルです。

## 概要

このスキルは、スライドデッキ用のSVG図を作成する際に必要な以下の情報を最小限の読み込みパスで提供します：

- SVG図の基本ルールとベストプラクティス
- レイアウトパターン（センタリング、2カラム、フル背景）
- カラーパレットと視覚的一貫性のガイドライン
- スライドへの埋め込み方法
- トラブルシューティング

## 特徴

- **視覚的一貫性**: 統一されたデザインシステムに基づくSVG作成ガイド
- **最小の読み込みパス**: スライド作成全体のルールではなく、SVGに必要な情報のみに集中
- **実用的なパターン**: よく使われるレイアウトと図形のテンプレート
- **検証ワークフロー**: svglintを使用した構文チェックの手順

## 使用方法

このスキルは、以下のようなタスク時に使用します：

- スライド用のアーキテクチャ図やフローチャートの作成
- SVGのサイジング、間隔、埋め込みルールの選択
- SVGのエクスポート/埋め込み問題のトラブルシューティング

## コアルールの概要

### 視覚的一貫性

同じプレゼンテーション内のすべてのSVGは、統一されたデザインシステムに従う必要があります：

- **同じカラーパレット**を使用
- **統一されたストローク幅**（例: 3pxまたは4px）
- **一様なボーダー半径**（例: 12pxまたは16px）
- **統一されたシャドウシステム**

### Canvas仕様

- `viewBox`はコンテンツの境界に密接させる
- センタリング図: 1200×675 または 1400×787（16:9維持）
- アイコン/バッジ: 200×200 から 600×400
- セーフマージン: 1920×1080キャンバス使用時に各辺120px

### 標準ワークフロー

1. **Design**: レイアウト、色、コンテンツを計画
2. **Create**: コアルールに従ってSVGコードを作成
3. **Validate**: `svglint file.svg` で構文チェック
4. **Fix**: エラーを修正（特にXML文字エスケープ）
5. **Test**: スライドに埋め込んでレンダリングを確認
6. **Commit**: 検証済みの動作するSVGのみコミット
